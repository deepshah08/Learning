# Can Users View Each Other's Notes

> **Article ID**: `900`  
> **Category**: `Application Guide > Notes > Can Users View Each Other's Notes`  
> **Client Compatibility**: `COMMON`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/900  

---

## Introduction

The Notes App stores Notes separately for each user account. After signing in, each user can only view the Notes that were created or imported under their own account.

If you switch to a different user account, the Notes from the previous account will not be visible. This is expected behavior.

## Are Notes Visible Across Different Users

By default, no. Each user's Notes are stored separately. Notes created by User A are not visible in User B's Notes App.

## Can an Administrator View a Regular User's Notes

No. An administrator cannot directly view a regular user's personal Notes in the Notes App.

Administrators can manage system settings, such as App installation. However, this does not give them access to a regular user's personal Notes in the Notes App.

## Can Regular Users Use the Notes App

Yes. The Notes App is available to regular users, and there are currently no access restrictions.

## How to Restrict User Access to the Notes App

User access restriction for the Notes App is currently not supported.

## Does the Notes App Support Shared Notebook

The Notes App currently does not support multi-user shared Notebook or collaborative editing.

If you need to share Notes with others, you can use the following methods:

● Export a single note as a **PDF** or **Markdown** file and send it to others.

● Export a Notebook as a **.ugnote** file, which can then be imported using the **Import notebook** feature.

If you only want to share selected Notes, you can first create a new Notebook, move the desired Notes into it, and then export that Notebook separately.

## Why Can't I See My Previous Notes After Switching Users

This is because Notes are isolated by user account. When you switch users, the system enters a different user's Notes space. Notes created or imported under the original user will not Appear under the current account.

If you need to access these Notes under another user account, the original user can first export the Notes or Notebook, and then the target user can import them.
