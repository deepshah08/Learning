## Applicability

**Applicable Client**: UGREEN NAS PC Client (Windows/macOS), Web Browser

**Applicable Version**: NAS Firmware 1.18.0.0093 or later

The descriptions in this document are for reference only. The interface and operation paths may vary depending on system or app updates, please refer to the actual interface.

## Introduction

When running apps that require AI computing capabilities, the underlying local AI models need to be maintained regularly. Through the "**Model Management**" module in this app, you can centrally manage the running status and version updates of all installed models.

## Enable or Disable Models

You can flexibly control model activity based on your NAS performance load or usage needs.

● **Single Model Control**: Go to "**Model Management**" from the left sidebar, locate the target model in the list, and open its detail page. Use the toggle switch to enable or disable the model.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/e389d6c4aa6f4844b9765eb972da7d1f.webp)

● **Disable All Models**: On the "**Model Management**" page, click "**Disable all**" at the bottom to stop all AI models with one click.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/a50905e016a447668f7d6b472d20d2c7.webp)

● **Restore All Models**: If all models were previously disabled, return to this page and click "**Restore model settings**" to reinstate their original running states.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/eaa839a431674627a5cca30174f67657.webp)

## Check and Update Models

To ensure optimal AI performance, it is recommended to keep models up to date. "**Model Management**" will automatically check for available updates. If updates are available, the page will display a notification along with the number of models that can be updated.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/927bf52882524b4fba465202ba12d7b2.webp)

Click "**Update all**", review the list of models to be updated in the pop-up window, and click "**Update**" again. The system will then download and deploy updates automatically in the background.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/768426ea68e7420ea29f08e05fe53797.webp)

**Note**:

● During the update process, the model and all associated app features will be temporarily unavailable.

● This update is a system-level operation. Once applied, it will directly affect all user accounts connected to this NAS device.

● After the update is complete, apps that have used this model (such as categorization in Photos) will automatically trigger reanalysis to apply the results generated by the latest model.

## Remove and Reinstall Models

If you no longer need a specific AI feature and want to fully free up the storage it occupies, you can remove the model.

● **Remove a Model**: In "**Model Management**", open the target model's detail page, click the "**...**" icon in the top-right corner, and select "**Remove**".

![](https://file-us.ugreennas.com/admin/article/2026-08-07/6e3593742bd04d0bac85b8dbc4f2de11.webp)  
After removal, all features that depend on this model will become unavailable immediately.

● **Reinstall a Model**: To restore functionality, exit and re-enter the model's page, then click "**Download**" to reinstall it. Once installation is complete, the model will be automatically enabled.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/91d46518a6e248a3bbe5672360549c53.webp)

## Manage App Model Permissions

In addition to managing models themselves, Model Management allows you to control which applications can access specific AI capabilities. You can configure permissions independently for different apps.

● **View and Grant Permissions**: In the Model Management app, click a target app (e.g., "**Photos**") from the left sidebar to view the list of models it is authorized to use.

● **Disable Specific Features**: If you want to prevent an app from using a certain AI capability (e.g., disabling "**Sensitive content recognition**" in Photos), locate the corresponding model in the list and turn off the toggle switch to revoke access.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/9ce07ba34c75442d9f30d37b02ec7189.webp)

## AI Data Storage Location and Migration

Data generated during AI processing (such as recognition results and cache files) is stored by default in the app's installation location (e.g., Volume 1). If you need to free up space, you can migrate this data to another storage location.

**Data Migration Steps:**

1. In the "**Model Management**" app, click the "**Settings**" icon (gear) at the bottom of the left sidebar.

2. Locate "**AI data storage**" and click "**Migrate data**".

![](https://file-us.ugreennas.com/admin/article/2026-08-07/0f3822ba2e6c480b8eae3f0c7102a932.webp)

3. In the pop-up window, select the target storage location and click "**Migrate**".

![](https://file-us.ugreennas.com/admin/article/2026-08-07/81fe095cf90845d9b8157f739819ca70.webp)

4. A security verification prompt will appear. Enter your account password and click "**Migrate**" again. After verification, the system will begin transferring data in the background.

![](https://file-us.ugreennas.com/admin/article/2026-08-07/295ade7e04ee46d4a2b9a5d8b84ffa9e.webp)

**Risk Warning**:

During the data migration task, the system-level AI computing resource access channel will be temporarily suspended. During this period, all AI-related features on the NAS will be unavailable. Once the data migration is fully complete, all features will automatically resume normal operation.
