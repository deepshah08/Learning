# Security

> **Article ID**: `225`  
> **Category**: `Application Guide > Control Panel > Security > Security`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/225

In the "Control Panel" > [Security] page, you can manage and protect UGOS Pro system security, including device login security, account security, enabling DOS protection, configuring IP blocking and whitelist, enabling firewall, and managing security certificates, providing comprehensive protection for system security.
