# Thunderbolt Device Not Recognized on Windows – How to Fix It

> **Article ID**: `608`  
> **Category**: `Troubleshooting > Hardware Failure > Thunderbolt Device Not Recognized on Windows – How to Fix It`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/608  

---

## **Problem**

When a Windows computer connects to a UGREEN NAS device via Thunderbolt cable but the Thunderbolt functionality is not recognized, it may be caused by the following reasons:

* Physical damage: Loose connection, damaged plugs or Thunderbolt port.
* Driver issues: Thunderbolt drivers not installed or outdated.

## **Solution**

1. Verify Hardware Support

* Ensure that your Windows computer is equipped with a Thunderbolt port (usually marked with a Thunderbolt logo).
* Check that the Thunderbolt cable and ports are intact. Make sure the cable is properly plugged in and the port is not loose or damaged.
* If the Thunderbolt cable is damaged, replace it with a certified Thunderbolt cable.

2. Update or Reinstall Thunderbolt Drivers

Update drivers: Visit the computer manufacturer's official website to download and install the Thunderbolt drivers that match your computer model, then try reconnecting.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250425/e2ee51b8-9e7d-41cc-b4b8-c768086851b1.png)

Reinstall the drivers: If updating the drivers doesn't work, try uninstalling the current Thunderbolt drivers. After restarting the computer, let the system automatically reinstall the drivers.

Install the Thunderbolt Control Center: If the computer manufacturer doesn't provide Thunderbolt drivers, you can download and install the [Thunderbolt Control Center](https://apps.microsoft.com/home?hl=en-us&gl=US) application from the Microsoft Store to view and manage devices connected via Thunderbolt.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250425/e8a2dbbf-1dd4-4c88-8744-d5cfe32013f4.png)

3. Contact Manufacturer Technical Support

If none of the above solutions resolve the issue, it's recommended to contact the computer manufacturer's technical support team for further assistance.
