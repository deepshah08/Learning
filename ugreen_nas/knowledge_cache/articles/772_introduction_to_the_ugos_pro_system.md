# Introduction to the UGOS Pro System

> **Category**: `Application Guide > UGOS Pro > Introduction to the UGOS Pro System`

**Applicable Models**: DH Series, DX Series, DXP Series, iDX Series

**Supported Version**: UGOS Pro firmware 1.18.0.0076 and higher

The screenshots in this document are for reference only. The actual user interface may vary slightly depending on the system or app version, please refer to the actual interface displayed on your device.

**UGOS Pro** is an operating system independently developed by UGREEN Technology for UGREEN NAS devices. Centered around stability and data security, it combines powerful data processing capabilities with a rich app ecosystem. It provides features such as file management, remote access, data protection, multimedia services, containerized applications, and AI-powered intelligent services, significantly enhancing the practicality and expandability of NAS devices.

![](https://file-us.ugreennas.com/admin/article/2026-07-31/26b3a9cceb7c4bc2a244b2a4e9f5c3a9.webp)

**Core features of the UGOS Pro system include**:

● **System Settings and Personalized Configuration**

Through the intuitive Control Panel, users can easily configure network settings, user permissions, hardware management, and other detailed options. These configurations help optimize system performance, allowing the NAS to better meet personal or team requirements and provide a customized user experience.

● **Stable and Reliable Storage Management**

Supports flexible storage pool creation with multiple RAID modes. Storage pools can contain multiple Volumes and work with features such as SSD cache acceleration and hard drive health monitoring to balance capacity, performance, and data security, meeting storage requirements across different scenarios.

● **App Management and One-click Updates**

The built-in App Center provides one-stop app installation, uninstallation, and update services, ensuring the system always runs with the latest and most compatible versions. It also offers both professional tools and entertainment apps, enabling convenient management for productivity and multimedia scenarios.

● **Remote Access and Security Protection**

With remote access services such as UGREENlink, users can securely access NAS data anytime and anywhere. The system features dual encryption and fine-grained permission control to ensure the security of data transmission and storage.

● **AI-powered Intelligent Organization and Classification**

Supports intelligent recognition and classification of image files. With multimodal semantic model technology, users can quickly search and retrieve files. It also supports similar and duplicate file cleanup, sensitive data protection, and other features to help efficiently manage large-scale image assets.

● **Multimedia Services and Containerized Applications**

Supports building home entertainment centers for movies, music, and photo libraries, providing smooth media playback performance. It also supports a wide range of Docker containerized applications, enabling rapid deployment and full lifecycle management of various image-based applications, significantly expanding device capabilities.

● **Virtual Machines and High-quality Third-party Applications**

Supports creating and managing multiple virtual machine instances on NAS devices, allowing users to run various operating systems, including Windows, Linux, iStore, OpenWRT, and iKuai. This simplifies virtualization deployment in home and office environments. In addition, the system integrates high-quality third-party app ecosystems such as OpenClaw and Hermes Agent, which can be accessed and used directly through the App Center.

● **Built-in Intelligent Assistant and AI Applications**

The built-in AI Assistant, powered by advanced AI technologies and model management services, supports semantic file search and intelligent Q&A based on file content. Through a series of AI applications, users can perform intelligent transcription, translation, and summarization of audio files, as well as intelligent analysis, classification, organization, and tagging of large volumes of files, making AI a key part of a smarter personal data center.

**Notes**：

● The DH2300 4GB version currently does not support Docker.

● DH Series products do not support Virtual Machine features.

● DXP/DX/DH Series products currently do not support Uliya, Voice Memo, or some AI application features.
