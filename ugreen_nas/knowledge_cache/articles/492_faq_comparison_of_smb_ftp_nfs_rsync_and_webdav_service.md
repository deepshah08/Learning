# [FAQ] Comparison of SMB, FTP, NFS, rsync, and WebDAV Service

> **Article ID**: `492`  
> **Category**: `Application Guide > Control Panel > File Service > [FAQ] Comparison of SMB, FTP, NFS, rsync, and WebDAV Service`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/492  

---

In the UGOS Pro system of UGREEN NAS, multiple file transfer protocols are supported, including SMB, FTP, NFS, rsync, and WebDAV. Each protocol has its own characteristics in terms of functionality, applicable scenarios, and configuration. This article will provide a detailed analysis of their features, use cases, and activation effects to help users choose the most suitable file service.

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **PROTOCOL** | **SMB** | **FTP** | **NFS** | **rsync** | **WebDAV** |
| **Introduction** | The SMB service is a versatile network file sharing protocol, widely used for file and resource sharing between different operating systems. With proper configuration and management, SMB can significantly enhance the efficiency and security of file sharing. Whether in a home network or an enterprise environment, SMB is an ideal file sharing solution. | FTP (File Transfer Protocol) is a standard protocol used for file transfer over a network. You can access and manage files stored on the NAS via the FTP protocol. FTP is known for being simple, fast, and efficient, and is widely used for file sharing and transfer. | NFS (Network File System) is an efficient network file sharing protocol widely used for file sharing, data backup and recovery, as well as multimedia storage and access. UGOS Pro offers a convenient, secure, and high-performance NFS service, with flexible configuration options to meet the diverse needs of users. | "rsync" is a fast and versatile file copying tool, widely used in NAS devices for data backup and synchronization. The use of rsync file services on UGOS Pro offers several advantages, including incremental backups, efficient network transfer, and data consistency. | WebDAV (Web Distributed Authoring and Versioning) is an extension of the HTTP protocol that enables easy file management and operations over the network. It offers a convenient way to remotely access and edit files on UGOS Pro, much like working with a local file system. |
| **Advantages** | * Native Support on Windows: SMB is the default file sharing protocol for Windows. | * Easy to Use: FTP is simple to set up and deploy.  * Wide Support: Almost all operating systems and devices support FTP, with many client software options available.  * Anonymous Access: Supports anonymous access, ideal for sharing and downloading public files.  * Large File Transfer: Suitable for transferring and backing up large files. | * Native Support on Unix/Linux: NFS is the native file sharing protocol for Unix and Linux systems, ideal for seamless file sharing between these systems. | * Efficient Synchronization：Utilizes incremental transfer to only transmit changed data, optimizing transfer speed and efficiency. | * Based on HTTP/HTTPS: WebDAV is based on the HTTP/HTTPS protocol, enabling access through a web browser, making it ideal for file sharing over the internet. |
| **Applicable**  **Scenery** | * Windows Environment: Commonly used by home and business users for data sharing and synchronization between PCs and NAS. | * Batch File Transfer: Ideal for regular backups or uploading large amounts of data to the NAS. | * File Sharing for Linux/Unix Systems: Suitable for file sharing between servers or mounting local file systems. | * Data Backup: Regularly sync data between NAS and external devices to ensure consistency. | * Cross-Device File Access: Ideal for users who need to access NAS files across different platforms (e.g., smartphone, tablet, PC). |
| **Outcome** | UGREEN cloud storage data can be accessed and connected to via SMB using local accounts within the local network. | UGREEN cloud storage data can be connected to and accessed via an FTP client using a local account within the local network. | UGREEN cloud storage data can be accessed via an NFS client after being enabled. The access permissions can be edited by the administrator on the shared folder management page. | Remote data backup to UGREEN cloud can be allowed from other UGREEN cloud devices or any devices that support rsync. | UGREEN cloud storage data can be accessed via webDAV using a local account from either the local network or external network. |
