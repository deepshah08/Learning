# File Version Explorer

> **Article ID**: `316`  
> **Category**: `Application Guide >  > File Version Explorer`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/316  

---

**File Version Explorer** is designed to manage the historical versions of files in shared folders with synchronization enabled through the **Sync & Backup** application. It provides version generation and restoration features, allowing you to effectively track and manage folder history, easily revert files to previous states, and ensure data security and integrity.

### **Main Use Cases:**

1. **Accidental Operation Recovery** – If a user mistakenly deletes or modifies a file, **File Version Explorer** allows restoration to a previous version, preventing data loss.
2. **File Status Tracking** – View the state of files at different points in time to understand content changes.
3. **Version Management** – For frequently modified files, such as project documents, **File Version Explorer** helps manage and record each change, making it easy to locate and restore any version.
