## Basic Search

**To search for a file or folder, follow these steps:**

1. Open "**Files**" and select the target folder that contains the file or folder you want to find.

2. Enter "**Keyword**" in the search bar in the upper-right corner to view the search results.

3. To clear all search history records, click "**Clear search history**".

## Advanced Search

Advanced Search provides a variety of conditions and operators to help you obtain more precise search results.

1. Open "**Files**" and select the target folder that contains the desired file or folder.

2. Click the "**Search**" icon next to the search bar in the upper-right corner to display the Advanced Search menu.

3. In the Advanced Search menu, specify the following search criteria:

● **Keyword**: Enter a keyword to search for files or folders with matching names.

● **Search range**: Select from the drop-down menu to define the search range and directory depth. You can choose the current folder, the current folder and its subfolders, or a custom search scope.

● **Type**: Limit the search to specific file types, or manually enter file extensions for custom searches.

● **Tag**: Select one or more tags to search for files or folders that have those tags applied.

● **Size**: Specify a minimum and maximum file size to search for files within that range. (If the minimum and maximum values are the same, only files of that exact size will be searched.)

● **Date**: Choose "**Modification date**", "**Creation date**", or "**Last opened**", then select a date from the calendar to find matching files.

4. Click "**Confirm**" to start the search, or click "**Reset**" to clear the criteria and define new search conditions.

5. After the search is complete, matching files will be displayed in the file list area of Files.
