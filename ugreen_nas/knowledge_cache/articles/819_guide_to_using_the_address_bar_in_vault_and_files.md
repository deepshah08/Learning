## Overview

To improve the efficiency and professionalism of NAS file management, the Vault and Files apps now support **directly entering or pasting paths in the address bar**. This allows you to quickly locate target directories, reduces the need for step-by-step navigation, and meets the needs of frequent and advanced users.

## Path Navigation and Location

### In Files

1. After opening the "**Files"** app, click the address bar at the top. The entire path will be selected.

2. Click it again to cancel the selection. The cursor will be placed at the clicked position for precise path editing.

3. Enter the full path in the address bar and press Enter to jump directly to the target directory.

![](https://file-us.ugreennas.com/admin/article/2026-03-31/d7ad26c9eb7f4055b4a382a7f789e7f5.webp)

**Notes:**

● When you click root directories such as "**Shared Folder**" or "**Personal Folder**" in the left panel, the address bar will appear empty, indicating you are at the top level.

● If you paste the path of a specific file, the system will automatically open its parent directory and highlight the file.

### In Vault

1. Open the "**Vault**" app and click the "**vault**" name in the title bar to activate editing mode.

2. Path editing, navigation, and file locating work the same as in the "**Files**" app.

![](https://file-us.ugreennas.com/admin/article/2026-03-31/57b8aa23e2ce40caac416966b486e1f5.webp)

### How to View and Copy File Paths

If you do not know the exact path of a file, you can quickly obtain it via the properties panel and paste it into the address bar.

1. Locate the target file or folder, right-click it, and select "**Properties**".

You can also select the file and press `Alt + Enter`.

2. In the "**Properties**" window, find the "**Location**" field.

3. Click the "**Copy**" icon on the right side of the path to copy the full file path.

![](https://file-us.ugreennas.com/admin/article/2026-03-31/f68077438af14e7e852b7a3019eff3cd.webp)

## Use Cases

### Scenario 1: Quick Access to Deep Directories

When frequently accessing paths such as `Shared Folder/Book/2026/epub`, you can enter the full path in the address bar to jump directly, without navigating through each folder.

### Scenario 2: Cross-Directory File Location

If you copy a file path from elsewhere (e.g., `/volume2/1001/doc/new.docx`), paste it into the address bar and press Enter. The system will open the parent directory `doc` and highlight `new.docx`, eliminating the need for manual searching.

### Scenario 3: Path Reuse

After performing cross-directory operations, you can copy the current path from the address bar and reuse it in another window or operation, avoiding repeated navigation.

## Notes

● The entered path must follow system format rules. Avoid using invalid characters or unsupported path segments.

● The address bar only allows access to directories or files you have permission to view. Unauthorized paths will be blocked automatically.

● To share the current directory, click the address bar, select all content, and copy it.
