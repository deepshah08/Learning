# Installing iStore on a Virtual Machine

> **Article ID**: `232`  
> **Category**: `Application Guide > Virtual Machine > FAQ > Installing iStore on a Virtual Machine`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/232  

---

The application features of UGREEN NAS vary across different product series. The Virtual Machine application is not supported on [DH Plus Series] devices. Please confirm your device model before use to ensure a complete experience.

(1) Click on "New" > "Import from OVA file" in the virtual machine.

(2) Taking the iStore OVA file as an example, select the OVA file and click "Next."

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250729/9dae0325-f0b1-4837-a329-1b10182be100.png)

(3) Choose the storage space for storing virtual machine instance data, check the storage space, and click "Next."

In this step, you need to set the virtual machine's name and network configuration. Choose the appropriate virtual network adapter type and connection mode based on your specific requirements. If you want to understand the differences in virtual machine network settings, you can click on "[Introduction to Virtual Machine Networking](https://support.ugnas.com/knowledgecenter/#/detail/eyJ0eXBlIjoidGFnMDAyIiwibGFuZ3VhZ2UiOiJlbi1VUyIsImlkIjo2NDIsImFydGljbGVJbmZvSWQiOjIzMywiY2xpZW50VHlwZSI6IlBDIiwiYXJ0aWNsZVZlcnNpb24iOiIiLCJwYXRoQ29kZSI6IiJ9)" for details.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250729/5cc3e30d-8509-4216-8ea0-af32d601ed63.png)

(4) After configuring the virtual machine name and network, click "Finish" to create the virtual machine instance.

(5) Once the virtual machine instance is created, find the instance on the virtual machine page and click on the "..." next to the instance entry > "Connect from new page" to access iStore's underlying.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250729/873a1ff1-b2e4-48dc-905c-cfba3e62aaf9.png)

(6) If this is the first time connecting to iStore, follow the on-screen instructions to press the Enter key to activate the console.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250729/3486850e-aa17-475f-a108-de2e28516299.png)

(7) After activating the console, we need to find the IP address of the virtual machine instance to access iStore's management interface. In the console, type "quickstart" and press Enter. Then use the "arrow key ↓" on the keyboard to select "0. Show Interfaces" and press Enter.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250729/b3763dd3-e461-4012-ad0d-fb24fb4b06ea.png)

(8) Here, you will see that the IPv4 address is 192.168.79.69. Open a new page in your browser and enter this IP address to access iStore.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250729/aa80b06a-228b-4bab-a278-0aa4672ae518.png)

(9) Successful access.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250729/590d6048-189d-4b62-98ac-20bb6b4b9ab2.png)
