# TV Show Categorization and Organization Method in the Theater

> **Article ID**: `568`  
> **Category**: `Application Guide > Theater > FAQ > TV Show Categorization and Organization Method in the Theater`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/568  

---

In the UGOS Pro system's theater, you can organize TV show resources to quickly find the content you need and optimize your viewing experience. This tutorial provides two common organization methods.

## **Method 1: Create Categorized Folders via Files to Organize Episodes**

Follow these steps:

1. Open [Files] and locate the folder where media data is stored (e.g.,  `Shared Folder/media`).
2. Create categorized folders as needed for easier management in the media library. Name the folders according to TV show genres, such as: American TV shows, Anime, Chinese dramas, etc.
3. Naming convention for TV show episodes: it is recommended to use the format “TV show name.Year.Season.Episode” (e.g., Friends .2019.S01E01). For more details, please refer to: [Movie Naming Convention Guidelines](https://support.ugnas.com/knowledgecenter-h5/#/articleDetail?custom=eyJpZCI6NzUwLCJ0eXBlIjoidGFnMDAyIiwibGFuZ3VhZ2UiOiJ6aC1DTiIsImNsaWVudFR5cGUiOiJQQyIsImFydGljbGVJbmZvSWQiOjI1NywiYXJ0aWNsZVZlcnNpb24iOiIiLCJwYXRoQ29kZSI6IiJ9)

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/e8c0fa07-d5f8-41a1-87fd-c416a01afd10.png)

4. Move the completedly named episode folders into the corresponding categorized folders.
5. Go to [Theater] > [Settings] > [Library], add the categorized folders, set the media library name, and add the media folder path.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/c3614f58-7ce1-4b70-b8a7-2c34ebf82b1c.png)

6. After setting up the Library, start the Library scan so that the theater can categorize, organize, and identify the episodes.

## **Method 2: Organize Episodes via the "Add Episodes" Feature**

Follow these steps:

1. Open [Theater], go to the Library, select the details page of a TV show, and add the show to the episodes.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/35b31a1f-62e3-46d3-bcd5-4b0c43de6b86.png)

2. Click "New Episode". If the corresponding episode has not been added yet, you can manually enter the episode name and season.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/cfcd3db9-8a5c-464e-81db-8cb5b8c3cb00.png)

3. Click "Episode Management" to manually correct any episodes that have not been recognized or have been incorrectly identified.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/9113aeeb-a3f4-44b3-a06f-ba7750101ac7.png)

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/f0e7c3a7-ec45-4dd6-bf2b-a343e4f01cb9.png)

## **Notes**

#### **Naming Convention: It is recommended to follow a unified naming rule to help the system accurately recognize and display episodes. The following format is suggested:**

* TV Show Name. Year. Season. Episode: For example, `A Certain Scientific Railgun.2010.S01E01.`
* Batch Renaming Tool: If there are many video files, it is recommended to use [the batch renaming feature](https://support.ugnas.com/knowledgecenter-h5/#/articleDetail?custom=eyJpZCI6MTM1NCwidHlwZSI6InRhZzAwMiIsImxhbmd1YWdlIjoiemgtQ04iLCJjbGllbnRUeXBlIjoiUEMiLCJhcnRpY2xlSW5mb0lkIjo0NTIsImFydGljbGVWZXJzaW9uIjoiIiwicGF0aENvZGUiOiIifQ%3D%3D) in Files to uniformly optimize the format.

#### **File Format Requirements**

* Ensure all video files are in [Supported Video Formats](https://support.ugnas.com/knowledgecenter-h5/#/articleDetail?custom=eyJpZCI6MTMwNCwidHlwZSI6InRhZzAwMiIsImxhbmd1YWdlIjoiemgtQ04iLCJjbGllbnRUeXBlIjoiUEMiLCJhcnRpY2xlSW5mb0lkIjo0MzMsImFydGljbGVWZXJzaW9uIjoiIiwicGF0aENvZGUiOiIifQ%3D%3D) compatible with the UGOS Pro system (e.g.,`.mp4`, `.mkv`, `.avi`).
* If there are external subtitles, please store the subtitle file in the same folder as the video file and ensure the names are consistent (e.g., `A Certain Scientific Railgun.2010.S01E01.mkv` and `A Certain Scientific Railgun.2010.S01E01.srt`).
