# Sync/Backup Task Shows "The task configuration file is missing. Delete the task and create it again."

> **Article ID**: `889`  
> **Category**: `Application Guide > Sync & Backup > FAQ > Sync/Backup Task Shows "The task configuration file is missing. Delete the task and create it again."`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/889  

---

## Applicability

**Applicable client:** UGREEN NAS PC Client (Windows/macOS).

**Applicable version:** NAS firmware 1.17.0.0034 or later.

The descriptions in this document are for reference only. The actual interface and navigation paths may vary slightly depending on your system or app version. Please refer to the interface displayed in your environment.

## Issue Description

After a sync or backup task is executed on the PC client, the message "**The task configuration file is missing, delete the task and create it again.**" is displayed. This message usually indicates that the local configuration file required by the task is missing, preventing the original task from running properly.

## Cause

This issue is usually caused by the **.stfolder-xxxx** configuration folder being missing from the sync directory on either the PC or the NAS.

Common causes include:

● The source folder used for the sync or backup task is automatically generated by another program and is periodically reset or overwritten.

● After mounting a NAS folder to the PC via SMB, the **.stfolder-xxxx** configuration folder in the NAS directory is accidentally deleted.

● Multiple users share the same NAS sync folder, and one user deletes the **.stfolder-xxxx** configuration folder on the PC, with the deletion then being synchronized to the NAS.

● Multiple users share the same NAS sync folder, and one user deletes the **.stfolder-xxxx** configuration folder on the PC, with the deletion then being synchronized to the NAS.

## Solution

Delete the task that displays the error message, and then create a new sync or backup task.

Follow these steps:

1. Open the UGREEN NAS PC Client, locate the sync or backup task that displays the error message, and delete it.

2. Create a new sync or backup task.

3. Select the original sync folder or backup folder.

4. Select the original sync folder or backup folder.

Recreating the task will not delete your synchronized data. However, because the original task configuration has been lost, it cannot be restored. You must create a new task.

## Notes

● Do not manually delete the **.stfolder-xxxx** configuration folder in the sync directory. This folder stores the configuration information required for the sync task.

● If the sync directory is automatically generated or periodically reset by another program, use a stable local folder or NAS folder before creating the task.

● If the same message still appears after recreating the task, contact UGREEN NAS Technical Support for further assistance.
