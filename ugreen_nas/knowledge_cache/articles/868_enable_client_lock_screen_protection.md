# Enable Client Lock Screen Protection

> **Article ID**: `868`  
> **Category**: `Application Guide > UGOS Pro > Enable Client Lock Screen Protection`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/868  

---

## Applicability

**Applicable client**: UGREEN NAS PC client (Windows/macOS).

**Applicable version**: NAS firmware 1.16.0.0042 or later.

**Requirement**: To use this feature, update the PC client to **V.1.16.0.77937 or later**. If the client version is earlier, update it first.

This document is for reference only. The actual interface and operation paths may vary slightly depending on system or app version updates. Please refer to the actual interface.

## Preparations

If the client does not meet the minimum version requirement, update it as follows:

1. Sign in to the system desktop, then click "**Me**" in the upper-right corner and go to "**Client**"or "**Client version**".

![](https://file-us.ugreennas.com/admin/article/2026-06-03/3443b5dd767e460fb56437215f93f3b3.webp)

2. Click "**Check for updates**".

If an update is available, an update prompt will appear. Click "**Update**" to download the latest installer. Once the download is complete, follow the on-screen instructions to finish the installation.

![](https://file-us.ugreennas.com/admin/article/2026-06-03/542d92da2e034e47bcb6b480c95b13af.webp)

## Enable and Set Up Lock Screen Protection

After updating the client to the latest version, lock screen protection can be enabled to protect data privacy.

1. Sign in to the system desktop, then click **"Me"** in the upper-right corner and go to "**Client**".

![](https://file-us.ugreennas.com/admin/article/2026-06-03/ad275fd45bea4d38b3d69b47042e3a58.webp)

2. On the settings page, turn on "**Lock screen protection**".

![](https://file-us.ugreennas.com/admin/article/2026-06-03/94d6c05b8e3745e1967a58c666b87b78.webp)

3. A password setup window will appear. Enter a **4-digit** lock screen passcode, then click "**Next**".

![](https://file-us.ugreennas.com/admin/article/2026-06-03/660af9a852544dae89861a51e3aad82a.webp)

4. A password setup window will appear. Enter a 4-digit lock screen passcode, then click "**Done**".

## Set Automatic Locking Rules

After lock screen protection is enabled, locking rules can be configured on the client settings page.

### Lock When the Computer Is Locked

Find "**Auto-lock when screen is locked**" and enable it. Once enabled, the UGREEN NAS client will lock automatically whenever the computer is locked.

![](https://file-us.ugreennas.com/admin/article/2026-06-03/ec311d33d7e14d399dfe864d286d81f9.webp)

### Set the Auto-Lock Time for Inactivity

Find "**Lock the client after inactivity**" and set when the UGREEN NAS client should lock automatically while the computer is idle, such as "**Never**", "**1 minute later**", or "**5 minutes later**".

## Reset the Passcode

To change the current lock screen passcode, click "**Reset lock screen passcode**" on the client settings page and set a new passcode in the pop-up window.

## Turn Off Lock Screen Protection

When lock screen protection is no longer needed, turn off "**Lock screen protection**" to disable it.

## Manually Lock the Client

When leaving the desk for a short time, the UGREEN NAS client can be locked manually in either of the following ways without waiting for the auto-lock countdown:

● **Method 1**: In the UGREEN NAS client, press **Ctrl + L** on the keyboard to lock the screen. This shortcut is available on Windows.

● **Method 2**: Click "**Me**" in the upper-right corner of the system desktop, then click "**Lock screen**" in the drop-down menu.
