# How to use an external wireless network adapter with UGREEN NAS?

> **Article ID**: `655`  
> **Category**: `Troubleshooting > Hardware Failure > How to use an external wireless network adapter with UGREEN NAS?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/655  

---

## **Preparation**

* Before using an external wireless network adapter, connect your NAS to a router or switch via Ethernet to ensure it is online.
* Insert a compatible UGREEN wireless adapter (such as AC1300 or AX1800) into the USB 3.0 port on the NAS. The system will automatically detect the hardware.

You can refer to the [UGREEN NAS Products Compatibility List](https://nas.ugreen.com/pages/compatibility) to check which models are supported by your NAS.

## **Configure Wireless Network**

1. Open the "Control Panel" app, go to [Network] > [Network Connection], and select the WLAN adapter.
2. Click the "Edit" button to search for and configure your wireless network connection.

Please note: On the [Network Connection] page in the "Control Panel", the [WLAN] adapter option is not displayed by default. It will only appear after a compatible wireless adapter has been properly connected and successfully recognized by the system. Once available, users can configure wireless network settings through the [WLAN] adapter.

## Troubleshooting

|  |  |
| --- | --- |
| Issue | Solution |
| WLAN adapter not shown in Network Connection | Check the [UGREEN NAS Products Compatibility List](https://nas.ugreen.com/pages/compatibility) to confirm whether the adapter model is supported. |
| Unable to find Wi-Fi networks | Connect the adapter to a PC to test if the hardware is functioning properly. |
| No network after connecting | Ensure that the router’s DHCP service is enabled, or try setting the IP address manually. |
| Slow transfer speed | Wireless networks use half-duplex transmission and are affected by Wi-Fi band and signal strength. Actual speed may vary. If you require higher speed and more stable performance, it is recommended to use a wired connection for better reliability. |
