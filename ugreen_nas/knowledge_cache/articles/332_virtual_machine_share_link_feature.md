## Applicability

**Applicable Version**: Firmware 1.18.1.0098 and higher

The screenshots in this document are for reference only. The actual interface may vary slightly depending on the system or app version, please refer to the actual interface displayed.

## Introduction

The **Virtual Machine** app supports creating share links for virtual machines. After a share link is created, it can be sent to others. Users with the share link can connect to the virtual machine through the link.

Share links support the following access methods:

● LAN

● Internet

## Create a Virtual Machine Share Link

1. Open the Virtual Machine app and find the target virtual machine in the virtual machine list.

2. Click "**···**" on the right side > "**Create share link**".

3. Select an access method, copy the link, and click "**OK**" to create it.

After creation, you can view the link in the "**Sharing link**" tab of the virtual machine details panel.

## Manage Share Links

1. Open the Virtual Machine app and click the target virtual machine in the virtual machine list.

2. The virtual machine details panel will be displayed on the right side of the page. Switch to the "**Sharing link**" tab to view the list of share links created for the virtual machine.

## Share Link Actions

Each share link provides three action buttons on the right side. From left to right:

● **Copy**: Copy the current share link.

● **Delete**: Delete the current share link.

● **Toggle**: Enable or disable the current share link.

After disabling the toggle, users will no longer be able to access the virtual machine through this link. To restore access, enable the link again.

## Can Virtual Machine Share Links Be Used on Mobile Phones?

Yes. You can copy the virtual machine share link to a mobile browser to access the virtual machine. The UGREEN NAS mobile app also supports viewing virtual machine share links. Follow these steps:

1. Open the "**Virtual Machine**" app and find the target virtual machine in the virtual machine list.

2. Click "**···**" on the right side > "**View shared link**".

After entering the page, you can view or copy the share link. After copying the link, paste it into a mobile browser to access the virtual machine.

## Can Virtual Machine Share Links Be Managed on Mobile Phones?

The UGREEN NAS mobile app currently supports **viewing** and **copying** virtual machine share links, but does not support managing share links.

To manage virtual machine share links, use the following clients:

● UGREEN NAS PC client

● Web browser

## Notes

● Share links do not support expiration settings. If a share link is no longer needed, delete the link or disable it.

● Each virtual machine can create up to **3** share links.

● When accessing through the Internet, the actual connection performance may be affected by the network environment.
