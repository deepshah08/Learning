# How to Batch Rename Files and Folders in Files?

> **Article ID**: `452`  
> **Category**: `Application Guide > Files > FAQ > How to Batch Rename Files and Folders in Files?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/452  

---

In the Files app of UGREEN NAS's UGOS Pro system, you can batch rename files and folders in multiple ways, significantly improving your work efficiency. Below are the detailed steps and answers to common questions:

## **Batch Renaming Files or Folders**

1、Open the [Files] app and use keyboard shortcuts or drag the mouse to select multiple files or folders.

* On Windows, hold the  `Shift` key to select a range of files or folders, or hold `Ctrl` to select non-contiguous items individually.
* On macOS, hold the  `Shift`key or `Command` (⌘) key to select multiple files or folders.

2、Once the files are selected, you can enter batch rename mode in either of the following ways:

* Click the **"Rename"** button in the top menu bar.
* Right-click on the selected files or folders and choose the **"Rename"** option.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/1bad7ef0-9628-4ae2-b031-46b20130914f.png)

3、After entering the batch rename window, you can choose from the following options based on your needs:

* **Find/Replace:** Enter a keyword to batch replace parts of the file or folder names, including file extensions.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/d4231efd-0696-40df-8de8-061e9105c7d0.png)

* **Number Format:** You can add serial numbers, prefixes, or suffixes to file or folder names to keep them organized.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/e6cf8e79-10e3-45c5-886a-0a61236a9d6c.png)

* **Add Content:** You can batch add text or numbers to the beginning or end of file or folder names.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/bb53e4c2-a383-4383-9b94-33b58435d298.png)

* **Edit manually:** Flexible custom naming is supported—you can manually edit the names of files or folders one by one.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/02e2d726-79a1-4a6e-a143-2911c3bcff29.png)

4、After configuring the renaming method, click the **"Rename"** button to confirm and apply all changes.

## **FAQs**

**Q1：What is the maximum number of files or folders that can be selected for batch renaming at once?**A1：You can select up to 2,000 files or folders at a time using the **Ctrl+A** shortcut for batch renaming. To rename more items, hold **Ctrl** and load additional files or folders across pages before continuing selection.

**Q2：Will the file extension be changed during batch renaming?**  
A2：By default, batch renaming only affects the file name and does not change the file extension—unless you manually modify the extension in the "Find/Replace" mode. Note: Changing file extensions in bulk may cause files to become unusable. Please proceed with caution.

**Q3：Can batch renaming be undone?**  
A3：After batch renaming, UGOS Pro currently does not support restoring the original file or folder names.
