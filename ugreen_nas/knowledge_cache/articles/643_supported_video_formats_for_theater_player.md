## Introduction

Theater app of UGREEN NAS features powerful decoding and media management capabilities. It supports scanning and organizing a wide range of mainstream and high-definition video formats for smooth playback. For more complex formats, such as split storage or those containing multiple video files (e.g., ISO, BDMV). The system also provides comprehensive multi-version management solutions.

## Supported Video Formats

Theater app currently supports scanning, organizing, and playback of the following video formats:

|  |  |  |
| --- | --- | --- |
| **Video Format** | **Format Description** | **Library Import and Playback Status** |
| **mkv, mp4, mov, avi** | Mainstream Container Formats | Supported |
| **rm, rmvb, flv, webm, 3gp** | Streaming and Web Video Formats | Supported |
| **m4v, mpeg, mpg, wmv, vob** | Common Media Formats | Supported |
| **ts, m2ts** | High-Definition Transport Stream Formats | Supported |
| **iso** | Disc Image Files | Supported |

## Import Rules for Special Formats (ISO / BDMV)

For Blu-ray original discs or image files, Theater follows these scanning and recognition rules:

● **Single ISO file:** Supported for direct scanning into the library and playback.

● **Multi-part ISO files:** If a video is split into multiple ISO files, the system will recognize them as separate video files, meaning multiple versions will be listed under the same video.

● **BDMV folder:** As a directory structure, if the BDMV folder contains multiple `.m2ts` or `.ts` video stream files, the system will recognize them as multiple versions of the same video.

## How to Switch Between Multiple Versions of a Video

When a video is recognized as multiple versions due to split ISO files or a BDMV structure, the desired version can be freely selected either before playback or from the details page.

### Steps on PC

1. In Theater, locate the target video that contains multiple versions and open its details page.

2. In the action bar on the details page, click the "**···**" icon.

3. In the pop-up menu, click "**Switch versions**."

4. From the version list, select the specific version you want to play to complete the switch.

1. In Theater, locate the target video that contains multiple versions and tap to open its details page.

2. On the details page, tap the "**···**" icon in the top-right corner, then select "**Switch versions**" from the pop-up menu.
