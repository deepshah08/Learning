# How to Create User Accounts in Bulk?

> **Article ID**: `315`  
> **Category**: `Application Guide > Control Panel > FAQ > How to Create User Accounts in Bulk?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/315  

---

When multiple employees in your company need to use the UGREEN NAS device, how can you quickly create user accounts? By reading this article, you will learn how to quickly complete the bulk creation of accounts when dealing with a large number of users.

# Introduction to User Management

The user management feature can greatly simplify the management of user accounts, improve work efficiency, and ensure the security of data and the effectiveness of user access permissions.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/43c0ed39eddf4e22989330788c2357a2.webp)

## Preparation Before Starting

1. User Import File: Prepare a file containing the employee information to be imported. The file should include basic information such as username, password, user role, and user group.

Note: If user groups are needed, please create the user groups in "User Group" first, and then fill in the corresponding information in the Excel file. Use a comma "," to separate multiple user groups.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/db0fd6994abe4ea8a1184b61e3f89d37.webp)

2. Permission Planning: Plan the permission groups for different employees according to the company's needs.

3. NAS System Access Permissions: Ensure that you have administrator permissions for the NAS system.

## Operation Steps

### Step 1: Fill in the User Import File

1. In [Control Panel > User Management > Add > Import users], click the "Download template" button in the lower left corner.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/581f67b04ffc45d8a5bbbb3c36b55e48.webp)

2. Fill in the user information according to the requirements in the template. After completing the filling, click the "Browse" button to import.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/4c80d5031e0845aebd8fe7c3171b304c.webp)

3. After the import is completed, you can set whether to force users to change their password upon first login.

4. After setting, click the "Import" button to import users in bulk.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/92bad1dd0deb4770bdb6ba7acfbdba1b.webp)

### Step 2: Connect the Device

After synchronizing the account information with company members, members can search for the device on the login page through the intranet, and log in by entering their username and password.

### Step 3: Create User Groups

To facilitate the management of members from different departments, you can set up different user groups.

1. In [User Management > User Group > Add], customize the name and description of the user group.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/4d596673718a42359476c5724d2b733c.webp)

2. Click "Next", and select the users to be added to the user group.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/8b8769fdc8c84be48ecb3f0cbed69b8e.webp)

3. Click "Next" again, and set the file read and write permissions for the members of the user group. After setting, click the "Done" button, and these users will be categorized into the same user group.

![](https://file-us.ugreennas.com/admin/article/2025-09-08/14c97487e869418fb1117fefecaac6c0.webp)

By following these steps, you can quickly and efficiently create and manage user accounts for your company's Ugreen NAS device.
