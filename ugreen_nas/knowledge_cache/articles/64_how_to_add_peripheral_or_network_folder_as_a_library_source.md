# User Management

> **Category**: `Video Tutorials > User Guide > How to Add Peripheral or Network Folder as a Library Source`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/64  

---

The User Management module provides administrators with efficient and detailed tools for managing user accounts, permission allocation, and access control strategies, ensuring system security and data privacy. Below is a detailed introduction to the module:

## **User Creation & Management**

* **Add Users**: Supports three methods for adding new users—"Create," "Invite," and "Import." When creating a user, administrators can set the username, password, role (regular user or administrator), and configure options such as enabling a personal folder and allowing password changes.
* **Manage Users**: Administrators can edit user information, including avatars, roles, and passwords, as well as assign access permissions to shared folders (No Access, Read & Write, or Read-Only).
* **Delete Users**: Administrators can remove user accounts that are no longer needed.

## **User Group Management**

* **Create User Groups**: Administrators can create new user groups, assign names, and add descriptions.
* **Edit User Groups**: Allows modifying group names and descriptions, as well as adding or removing members.
* **Permission Settings**: Configures group access permissions for shared folders.

If a [user's individual permissions conflict with their group permissions, the system follows a priority rule](https://support.ugnas.com/knowledgecenter/#/detail/eyJpZCI6MTUyMiwidHlwZSI6InRhZzAwMiIsImxhbmd1YWdlIjoiZW4tVVMiLCJjbGllbnRUeXBlIjoiUEMiLCJhcnRpY2xlSW5mb0lkIjo1MjQsImFydGljbGVWZXJzaW9uIjoiIiwicGF0aENvZGUiOiIifQ==): No Access > Read & Write > Read-Only, ensuring consistent and effective permission management.

## **Permission Viewer**

* **View User Permissions**: In the [User Management] page, administrators can use the "Permission Viewer" to check shared folder access permissions for each user and filter by user or folder.
* **View User Group Permissions**: Similarly, in the [User Group Management] page, the Permission Viewer allows checking access permissions assigned to groups and their associated shared folders.

## **Advanced Settings**

* **Password Strength Rules**: Administrators can define password strength requirements for new users to enhance account security.
