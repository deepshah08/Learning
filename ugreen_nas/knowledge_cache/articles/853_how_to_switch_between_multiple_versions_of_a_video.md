## Introduction

When multiple versions of the same movie exist in your media library (e.g., 1080P, 4K, DV, HDR versions), or when the system identifies multiple separate video files due to downloaded split-volume ISOs or BDMV Blu-ray structures, you can manually select the specific file you want to watch before playback using the "**Switch versions**" feature.

## Steps on PC

1. In Theater, locate the target video that contains multiple versions and click to open its details page.

2. In the action bar on the details page, click the "**···**" icon.

3. In the pop-up menu, click "**Switch versions**."

4. From the version list, select the specific version you want to play to complete the switch.

## Steps on Mobile

1. In Theater app, locate the target video that contains multiple versions and tap to open its details page.

2. On the details page, tap the "**···**" icon in the top-right corner.

3. then select "**Switch versions**" from the pop-up menu.

![](https://file-us.ugreennas.com/admin/article/2026-05-13/2a7cfe4580c14f6fbd8142903dbb3f24.webp)

4. In the version list, select the specific video version you want to play to complete the switch.
