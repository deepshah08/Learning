# [FAQ] How to recover or delete unavailable songs from a playlist?

> **Article ID**: `648`  
> **Category**: `Application Guide > Music > [FAQ] How to recover or delete unavailable songs from a playlist?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/648  

---

## **What are unavailable songs?**

Unavailable songs refer to tracks that have been removed from the library (possibly due to deletion, admin-restricted access, or personal settings that limit viewing to one's own library) but still remain listed in playlists. These songs are temporarily inaccessible in the library, but their records are retained in playlists so they can be restored once the library becomes available again.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250427/ba89b401-2b08-4934-a7a3-3ef16201f0b1.png)

## **How to recover unavailable songs?**

If a playlist contains unavailable songs, you can recover them in the following ways:

**Scenario 1:** Songs became unavailable because they were deleted by the admin or the user from a folder.

**Recovery method:**

1. Restore the deleted music files from the Recycle Bin in the "Files" app.
2. Return to the playlist page and refresh to recover the unavailable songs.

**Scenario 2:** The admin has set the user's access to the shared library as "Access Denied," causing songs from that library in the user's playlist to become unavailable.

**Recovery method:** Contact the admin and go to the "Music" app's [Settings] page. Change the user's access permission from "Access Denied" to either "Play Only" or "Editable."

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250427/b79b205a-91bc-4ec8-87f3-73ac9aaae7a3.png)

**Scenario 3:** If the admin sets the shared library access permission to "Personal Library Only," songs from the shared library will become unavailable in both the admin's and users' playlists.

**Recovery method:** Contact the admin and go to the "Music" app's [Settings] page. Change the shared library access permission back to "Personal library and shared library." After refreshing the playlist page, the unavailable songs will be restored.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250427/22f63604-8e92-4fca-bd18-87fad1584b2b.png)

## **How to delete unavailable songs?**

To delete unavailable songs from a playlist, click the "..." button on the playlist page, select "Clear Unavailable Music," and confirm to complete the deletion.
