# How to Import, Export, and Back Up Notes

> **Category**: `Application Guide > Notes > How to Import, Export, and Back Up Notes`  
> **Client Compatibility**: `PC`

## Introduction

The Notes App supports importing and exporting Notebook, as well as exporting individual Notes or multiple Notes. When exporting Notebook, the system saves it as a private **.ugnote** file format. When importing Notebook, you can restore the Notebook content from a **.ugnote** file.

When exporting Notes, they can be exported in **Markdown** or **PDF** format, making it easy to share, back up, or archive content.

## Entry for Importing and Exporting Notebook

1. Open the Notes App and click "**Settings**" at the bottom of the left sidebar.

2. In the pop-up window, select the function you want to use.

The Settings pop-up includes the following options:

● **Import notebook**

● **Export notebook**

### Exporting Notebook

Exporting Notebook will include all Sections and Notes within the selected Notebook. Follow the steps below:

1. Click "**Export notebook**", select the Notebook you want to export, then click "**Next**".

2. Choose a save location: **Local** or **NAS file system**, then click "**Export**".

3. Wait for the system to complete the export.

**Notes**:

● When exporting a single Notebook, the system generates a **.ugnote** file.

● When exporting multiple Notebooks, the system generates a compressed package. After extraction, each Notebook will correspond to a separate **.ugnote** file.

● Export Notebook exports the entire Notebook. Currently, selecting and exporting a specific section or individual Note is not supported.

### Importing Notebook

You can restore Notebook from a **.ugnote** file by importing it. Follow the steps below:

1. Click "**Import notebook**".

2. Select the import source: **Local** or **NAS file system**, then click "**Next**".

3. Select the **.ugnote** file you want to import.

4. Wait for the system to complete the import.

After the import is completed, the imported Notebook will appear in the left sidebar.

## What Should I Do If the Notebook Already Exists During Import?

If the system detects that an identical Notebook or Notebook name already exists, a pop-up window will appear.

![](https://file-us.ugreennas.com/admin/article/2026-07-07/b566264347c6424da3992a90e98f8397.webp)

You can choose one of the following options:

● **Cancel**: Stop the import.

● **Overwrite**: Replace the existing Notebook with the imported one.

● **Keep both**: Retain the existing Notebook and import the new one as a separate copy.

Before selecting "**Overwrite**", please confirm whether the existing Notebook still needs to be kept. If you are unsure, it is recommended to choose "**Keep both**" to avoid accidentally overwriting existing Notes.

## Exporting a Single Note

Notes can be exported in Markdown or PDF format. You can export a single Note from either of the following entry points:

● In the middle list, hover over a Note and click the "**···**" that appears on the right.

● Open a Note and click the "**···**" at the top of the right editing panel.

Follow the steps below:

1. Open the Notes App, locate the Note you want to export, and click the corresponding "**···**".

2. Select "**Export as Markdown"** or "**Export as PDF**".

3. Choose a save location, then click "**Export**".

4. Wait for the system to complete the export.

Exported files can be saved to a local computer or to the NAS file system.

## Batch Exporting Notes

To export multiple Notes at once, you can use the batch selection feature.

Follow the steps below:

1. At the top of the middle list, click "**Batch select**" and select the Notes you want to export.

2. In the bottom action bar, click "**Export**".

3. Follow the page prompts to choose the export format and save location.

4. Wait for the system to complete the export.

## What Is the Difference Between Markdown and PDF

**Markdown**: Suitable for sharing with users who need further editing. Markdown files can be opened and modified in editors that support the Markdown format.

**PDF**:Suitable for sharing with users who only need to read the content. PDF files are less likely to be modified accidentally and are better suited for archiving, printing, or formal distribution.

## Notes

● Exported files are a copy of the current Notes content. If you continue editing the original Notes after exporting, the exported file will not be updated automatically.

● If a Note contains images, they cannot be exported when exporting in Markdown format.

● If a Note contains images, tables, or special formatting, it is recommended to export in PDF format to reduce layout differences.

● **.ugnote** is a proprietary format of the Notes App, primarily used for Notebook backup, migration, and restoration.
