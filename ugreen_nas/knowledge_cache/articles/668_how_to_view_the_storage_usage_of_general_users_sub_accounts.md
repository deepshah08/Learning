# How to View the Storage Usage of General Users (Sub-Accounts)

> **Article ID**: `668`  
> **Category**: `Application Guide > Files > FAQ > How to View the Storage Usage of General Users (Sub-Accounts)`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/668  

---

If you want to check the storage usage of a general user (sub-account) on UGREEN NAS, follow the steps below:

1. Log in to the UGREEN NAS with an administrator account；
2. Open the “Files” application；
3. In the left-hand directory, click on “User Folder” and locate the folder of the user you want to check；
4. Right-click the user’s folder and select “Properties”；

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250509/8440d2a9-31c0-4122-9fde-bf64e6bb244a.png)

5. In the pop-up Properties window, you can view the current storage usage of the selected user.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250509/65116af5-fd5a-4a1e-8ea1-e1229843eb3c.png)

**Note:**

This method only displays the storage usage within the user's personal folder. If the user has stored files in shared folders, that portion of data is counted toward the overall NAS capacity and cannot be attributed to a specific user—therefore, it will not be shown here.
