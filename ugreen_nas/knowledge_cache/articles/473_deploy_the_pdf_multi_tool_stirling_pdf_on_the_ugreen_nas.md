## Introduction to Stirling-PDF

Stirling-PDF is a powerful PDF toolbox that offers a wide range of commonly used PDF processing features. These include adding or removing PDF passwords, merging or splitting PDFs, compressing PDFs, converting PDFs to Word, images, and more, meeting all your PDF-related needs.

### Access the Docker Project Interface

On the UGOS Pro system of UGREEN NAS, open the Docker application, navigate to [Project]>[Create] to launch the project creation wizard.

### Configure the Docker Compose File

In the project creation wizard, you will need to upload the Docker Compose configuration file. Below is an example configuration for Stirling-PDF.

```
services:  # Defines the list of services
  stirling-pdf:  # Name of the service
    image: frooodle/s-pdf:latest  # Specifies the image and version of the container
    ports:  # Port mappings between the host and the container
      - '8080:8080'  # Maps port 8080 of the host to port 8080 of the container
    volumes:  # Defines volume mappings for storage
      - ./trainingData:/usr/share/tesseract-ocr/5/tessdata  # Mounts the trainingData folder on the NAS host to the container's tessdata directory for additional OCR language support
      - ./extraConfigs:/configs  # Maps the host's extraConfigs folder to the container's /configs directory
      - ./customFiles:/customFiles/  # Maps the host's customFiles folder to the container's /customFiles directory
      - ./logs:/logs/  # Maps the host's logs folder to the container's /logs directory
    environment:  # Sets environment variables
      - DOCKER_ENABLE_SECURITY=false  # Disables default security restrictions by setting DOCKER_ENABLE_SECURITY to false
```

**Parameter Explanation:**

● **services:** Defines the services section in the Compose file. Here, a service named `stirling-pdf` is defined.

● **image:** Specifies the Docker image name and version. `frooodle/s-pdf:latest` indicates using the latest version of the `frooodle/s-pdf` image.

● **ports:** Configures port mapping, mapping the container's internal port (8080) to port 8080 on the host (UGREEN NAS), allowing external access.

● **volumes:** Mounts directories from the host (UGREEN NAS) to specific paths inside the container, providing data or configuration support:

● `./trainingData:/usr/share/tesseract-ocr/5/tessdata`: `./` represents the directory where the Docker Compose file is located. This mounts the `trainingData` folder on the NAS to the container's `tessdata` directory, supplying OCR language files for multi-language OCR support.

● `./extraConfigs:/configs`: Mounts the `extraConfigs` folder on the NAS to the container's `/configs` directory for storing custom configuration files.

● `./customFiles:/customFiles/`: Mounts the `customFiles` folder on the NAS to the container's `/customFiles/` directory for storing additional files used by the application.

● `./logs:/logs/`: Mounts the `logs` folder on the NAS to the container's `/logs/` directory. Logs generated by the container will be saved in the NAS `logs` folder.

● **environment:** Sets the environment variable `DOCKER_ENABLE_SECURITY` to `false`, disabling the default security restrictions.

### Deploying the Project

After confirming the configuration, click [Deploy]. The system will automatically pull the image and start the container. Once deployment is complete, you can access the Stirling-PDF webpage at `http://<NAS_IP>:8080`.

## Notes

● The storage space for the container and the configured file/folder paths are for reference only. You can create them according to your personal habits.

● Port configuration: It is recommended to keep the container’s web access port and the local port the same. If there is a conflict with the local port, change it to an unused port.

● The local ports between containers must not be the same. A port conflict will prevent the container from starting.

● The quick access web link for the container is only accessible in bridge mode.

● The image only provides instructions for setting up the container. For usage methods and advanced features, please search for tutorials online for reference.

● The image is developed by a third party. For specific configuration changes and bug fixes, please pay attention to relevant official information.

● It is recommended to store the Docker configuration directory on an SSD hard disk to avoid the mechanical hard disk from failing to enter sleep mode, which could affect system performance.
