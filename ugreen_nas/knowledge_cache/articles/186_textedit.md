# App Introduction

TextEdit is a lightweight code and text editor that supports viewing and editing multiple plain text formats online. You can quickly open files via "**Files"**, "**TextEdit"**, "**Universal Search"**, or desktop shortcuts.

The system intelligently recognizes programming or markup languages based on file extensions and provides syntax highlighting for a clearer code structure.

## Install the App

Open the "**App Center"**, locate "**TextEdit"** in the app list, and click Install.

![](https://file-us.ugreennas.com/admin/article/2025-09-12/72519cccead44440930c0259197df18f.webp)

## Quick Start

After entering TextEdit, you can perform the following operations via the menu bar:

**File Menu Operations:**

● Click the "File" menu to create a new blank txt file, open files from "Files", quickly access your recently edited file list, or save one or more currently opened files.

**Edit Menu Operations:**

● Click the "**Edit"** menu to perform standard editing actions such as copy, cut, paste, undo, redo, and select all. All these operations support keyboard shortcuts.

**Bottom Toolbar:**

● Encoding: Switch file encoding formats to resolve garbled text issues.

● Zoom: Adjust font size and text scale for better readability.

● Language Mode: Supports multiple programming languages with automatic syntax highlighting of variables, functions, and keywords.

## File Tab Management

For opened files, hover over the top tab and right-click for quick actions:

● **Right-click the file name:** you can perform **Rename** or **Close Tab**.

● **Navigate to File Management**: If the file was opened from "Files", click this option to directly locate the file in the "Files" app.

![](https://file-us.ugreennas.com/admin/article/2025-09-12/41543fa1991b4fbe8172a1526ec2eb64.webp)

## Find & Replace

Click the "**Search"** menu to open the "Find & Replace" window. Enter text to quickly locate content.

To achieve more precise searches, the search function provides the following advanced options:

**Find & Replace:**

● Click the drop-down arrow ˅ on the left side of the input box to expand the replace input field. After entering the text you want to replace, you can choose "**Replace"** to replace matches one by one, or "**Replace All"** to replace all matches at once.

**Full Word Match:**

● Only matches complete words that exactly match the input.

**Case Sensitive:**

● When enabled, the search strictly distinguishes between uppercase and lowercase letters.

**Regular Expressions:**

● When enabled, advanced searches are performed using regular expression syntax. A regular expression is a sequence of characters used to define complex search patterns. For example: `M[ea]rry` matches both **Merry** and **Marry.**

## Settings Menu

In TextEdit, click the "**Settings"** button in the upper-right corner to personalize the editor, customizing text display, editing preferences, and file opening behavior.

### Appearance

On this page, you can adjust the editor’s display style according to your preferences:

● **Show line numbers:** Display or hide line numbers on the left side of the editor.

● **Show hidden characters:** When enabled, invisible characters such as spaces and tabs are displayed with special symbols.

● **Show indent guide:** When enabled, vertical alignment lines appear in the indentation area, making the code structure clearer.

● **Display:** Switch between different interface themes (e.g., light/dark mode) for the best visual experience.

![](https://file-us.ugreennas.com/admin/article/2025-09-12/99da95ad6fcd46418997e2ba19ada55a.webp)

### Edit

On this page, you can control the behavior of text editing:

● **Line Wrap**: When enabled, text that exceeds the visible width of the editor will automatically wrap to the next line, avoiding horizontal scrolling. You can also set specific wrapping rules.

● **Indent Mode**: Choose whether pressing the `Tab` key inserts a Tab character or a specified number of spaces.

● **Indent Character Width**: Define the number of spaces represented by one Tab key or an automatic indentation (e.g., 2 spaces or 4 spaces).

![](https://file-us.ugreennas.com/admin/article/2025-09-12/a89d8502a41d485989d1454fd7d4e99b.webp)

### File

On this page, you can manage file opening and recovery behavior:

● **Record recently opened files:** Record recently opened files in the "Open" menu.

● **Path memory:** Automatically jump last selected file location when opening a file.

● **Auto-restore files:** Reopen unclosed files automatically the next time you open the app.

![](https://file-us.ugreennas.com/admin/article/2025-09-12/568984280b7b40b2934a77fa62c3347e.webp)

## Supported File Formats

The following is a list of file formats supported for direct opening. For file formats not included in this list, the "TextEdit" app will attempt to open them using `UTF-8` encoding and plain `text`format by default.

For easier reference, the supported formats are categorized by usage:

**Web Development**: `.html`, `.htm`, `.xml`, `.xsl`, `.js`, `.css`  
**Programming & Scripts**: `.py`, `.pyc`, `.sh`, `.c`, `.cpp`, `.cs`, `.java`, `.sql`, `.php`  
**Config & Data Formats**: `.cfg`, `.config`, `.yaml`, `.yml`, `.ini`, `.json`, `.csv`  
**Windows Scripts**: `.bat`, `.cmd`  
**Markup & Plain Text**: `.md`, `.txt`  
**Logs & Info**: `.log`, `.nfo`  
**Subtitles**: `.srt`, `.lrc`, `.ass`  
**Web Apps**: `.asp`, `.aspx`
