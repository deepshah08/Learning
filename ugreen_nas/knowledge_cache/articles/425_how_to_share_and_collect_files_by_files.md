# How to Share and Collect Files by "Files"?

> **Article ID**: `425`  
> **Category**: `Application Guide > Files > FAQ > How to Share and Collect Files by "Files"?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/425  

---

In the UGOS Pro "Files", you can set up file sharing and file collection through UGREENlink, sharing files with other UGOS Pro users and non-UGOS Pro users. This article will provide a detailed introduction on how to use the "Files" features of UGOS Pro to create file sharing and collection links.

### How to Create a File Sharing Link via UGREENlink

UGREENlink allows you to connect to your NAS over the network via a customizable address such as https://ug.link/UGREEN ID (e.g., `https://ug.link/1234`), without the need to set up port forwarding rules. Here are the steps to create a file sharing link:

1. Go to [Control Panel > Device Connection > Remote access], and check the box to enable the "UGREENlink remote access" checkbox.

2. In the UGREENlink ID field, specify a new ID, then click "Apply."

**Tips:** The ID must be a unique, memorable string, such as: 1234.

3. After obtaining the specified UGREENlink ID, the interface will display the addresses for the UGOS Pro web interface and client below. You can access UGOS Pro using the provided links.

![](https://file-us.ugreennas.com/admin/article/2025-09-16/3e09a55cad5246eeb0b6b74fcb31cf00.webp)

4. Open the Files, select the file or folder you want to share, right-click and choose **"Share."**

![](https://file-us.ugreennas.com/admin/article/2025-09-16/5d7f307ab1dd4dd4bb24022ec740c03a.webp)

5. In the sharing dialog, you can choose to share files with users within this device and external users. Additionally, you can set options such as the sharing expiration date, access password, and allowed access attempts.

![](https://file-us.ugreennas.com/admin/article/2025-09-16/85a89a1717f6408ea707189dcb239617.webp)

6. After setting up, click **"Confirm,"** and the system will generate a shareable link. You can copy this link and share it with others for file access.

![](https://file-us.ugreennas.com/admin/article/2025-09-16/6e6d3ed5cfc34f03baaacaf78951a104.webp)

### How to Create a File Collection Link via UGREENlink

Using UGREENlink, you can also create a file collection link that allows others to upload files to a specified folder. The steps are as follows:

1. Open the "Files", right-click on the folder to which you want others to upload files, and select **"**Request files**"**

![](https://file-us.ugreennas.com/admin/article/2025-09-16/075205bc6ece40ddb2d6acacf602d383.webp)

2. Set the desired expiration date, password, and allowed access attempts for file collection as needed.

![](https://file-us.ugreennas.com/admin/article/2025-09-16/76567d9c44454058892825196bb7fecd.webp)

3. After clicking **"Confirm,"** the system will generate a link for file collection. Copy this link and send it to others so they can upload files via the link.

![](https://file-us.ugreennas.com/admin/article/2025-09-16/9e0e893bf3164c0d85edc8672d482fca.webp)
