# Mount OneDrive Using the Network folder Feature

> **Article ID**: `906`  
> **Category**: `Application Guide > Files > Network Folder > Mount OneDrive Using the Network folder Feature`  
> **Client Compatibility**: `COMMON`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/906  

---

## Applicability

**Applicable Version**: NAS Firmware 1.18.0.0034 or later.

The descriptions in this document are for reference only. The interface and operation paths may vary depending on system or app updates, please refer to the actual interface.

## Introduction

UGREEN NAS supports mounting OneDrive through the "**Network folder**" feature. After mounting, you can view and manage OneDrive files in Files.   
You can also add the mounted OneDrive folder to the **Theater** Library to generate a poster wall and enhance your viewing experience.

## Feature Overview

After mounting OneDrive, you can perform the following operations on the NAS:

● View and manage OneDrive files in Files, and play videos stored in OneDrive.

● Add OneDrive folders to the Theater Library.

You can directly play videos in OneDrive without downloading them to the NAS in advance.

## Mount OneDrive on PC

Follow the steps below:

1. Open **Files**, click "**+**"＞"**Connect to network folder**" in the top toolbar.

![](https://file-us.ugreennas.com/admin/article/2026-07-28/6deddef248df483683d34feea084f3aa.webp)

2. Select "**OneDrive**", then click "**OK**".

![](https://file-us.ugreennas.com/admin/article/2026-07-28/d9e58772a74a44c18de900bf05d8d396.webp)

3. The system will open the OneDrive sign-in page in your browser. Follow the on-screen instructions to complete account sign-in and authorization.

After authorization is complete, OneDrive will appear as a folder in the **Network folder** list.

![](https://file-us.ugreennas.com/admin/article/2026-07-28/0de05da16df6409eae833871da60ae51.webp)

## Mount OneDrive on Mobile

Follow the steps below:

1. Open **Files**, tap "**+**">"**Connect to network folder**".

2. Select "**OneDrive**".

![](https://file-us.ugreennas.com/admin/article/2026-07-28/900e77134333457e951dd7e683f06ed7.webp)

3. The system will open the OneDrive sign-in page in your browser. Follow the on-screen instructions to complete account sign-in and authorization.

After authorization is complete, OneDrive will appear as a folder in the **Network folder** list.

## Use OneDrive in Files

After OneDrive is mounted successfully, you can access **Network folder** from the left navigation pane in **Files**. Tap the mounted OneDrive folder to view the files inside.

Depending on the actual permissions and available page functions, you can browse, play, copy, move, and perform other operations on files.

## Add OneDrive to the Theater Library

To manage OneDrive video files in Theater, you can add the mounted OneDrive folder as a Media folder.

After adding it, Theater can scan the media files in this directory and generate the corresponding poster wall.

For specific steps, refer to the actual display on the Theater Library adding page.

## Notes

● The OneDrive sign-in and authorization page is provided by OneDrive. Follow the on-screen instructions to complete the process.

● Before using this feature, make sure the current network environment can access OneDrive services properly.

● Online video playback quality is affected by the network environment, file size, and OneDrive access speed.

● If OneDrive authorization expires, sign in and authorize again.

● The page names and feature entry points may vary slightly depending on the system version. Refer to the actual interface.
