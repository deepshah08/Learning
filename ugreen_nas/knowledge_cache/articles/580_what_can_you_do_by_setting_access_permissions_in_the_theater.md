# What Can You Do by Setting Access Permissions in the Theater App?

> **Article ID**: `580`  
> **Category**: `Application Guide > Theater > FAQ > What Can You Do by Setting Access Permissions in the Theater App?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/580  

---

The access permission management feature in the Theater app is designed to meet the needs of personalization and security in multi-user environments. By assigning different levels of access, administrators can precisely control each user’s access scope and operational permissions within the Library.

1. **Access Levels for the Library**

**Block Access**: The user cannot view or access the content of the specified library.

**Allow Access**: The user can view, search, and play content within the library but cannot modify or delete anything.

**Administrator Access**: The user has full access to the library, including adding and deleting content, editing metadata, and changing settings.

2. **Scope of Application:** Applies to all user roles.

## **How to Set Access Permissions**

1. Open the "Theater" app and click the [Settings] button in the upper-right corner.
2. In the settings interface, click "User Management" from the left-hand menu.
3. In the user list, locate the target user and click [Set Permissions].
4. Set the user's access level for each library as needed (e.g., Allow Access, Block Access).
5. Click “Apply” to save the settings.
