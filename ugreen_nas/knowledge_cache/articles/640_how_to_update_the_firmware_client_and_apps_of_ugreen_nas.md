## Firmware Update Method

### Method 1: Online Update (Recommended)

**Applicable Scenario:** When the system pushes the latest firmware version.

**Steps:**

1. Go to the "Control Panel" and click [Update & Restore] > [Update].

2. The system will automatically check whether the current version has an available update. If a new version is found, a prompt will notify the user to update immediately.

![](https://file-us.ugreennas.com/admin/article/2025-08-28/5b09017277ef474aad13650659875a50.webp)

3. During the upgrade process, the device will automatically restart (this is normal behavior).

### Method 2: Manual Firmware Update

**Applicable Scenario:** For installing a specific version or when no system update has been pushed.

**Steps:**

1. Visit [the official UGREEN website's firmware download page](https://www.ugnas.com/support/download-list/id-13?type=2) and select the appropriate firmware package based on your device model (the downloaded firmware version must be newer than the current device version).

![](https://file-us.ugreennas.com/admin/article/2025-08-28/3ee09365848046d7b2e4b9d31b018909.webp)

2. After the firmware is downloaded, go to the "Control Panel" and click [Update & Restore] > [Update].

3. On the page, click [Manual Installation], select the downloaded firmware package. Once the system verification is complete, click [Confirm Upgrade] and wait for the automatic restart.

![](https://file-us.ugreennas.com/admin/article/2025-08-28/8eb6b378cc6348bb8611dd84e8d10dca.webp)

## Application Update Method

**Applicable Scenario:** When the application receives an update notification.

**Steps:**

1. Go to the "App Center".

2. In the app list, applications that have received an update push will display an "Update" button.

3. Click "Update" and the system will automatically complete the installation.

4. Select [Installed], where you can update all installed applications with one click.

![](https://file-us.ugreennas.com/admin/article/2025-08-28/f3a0da3a54ed4b8c9b9488845b03561e.webp)

## Download and Update the Client

To ensure you always enjoy the best experience with your UGREEN NAS, we provide convenient ways to download and update the client.

### Client Update Methods

● **Automatic Update Push:** UGREEN NAS client updates are usually pushed automatically to your device. When a new version is available, the client will prompt you to update, ensuring you receive the latest feature improvements and security patches in a timely manner.

● **Beta User Exclusive Downloads:** If you are a beta user of UGREEN NAS, Beta versions will be pushed based on your reported device serial number (SN). If you do not receive the Beta version update, please contact our staff to join the beta group and obtain the upgrade according to the group announcements.

### Download the UGREEN NAS Client

For first-time downloads or if you need to manually obtain the latest installation package, please visit[the UGREEN NAS Download Center](https://nas.ugreen.com/pages/downloads) .

There, you can find client versions for various operating systems, including Windows, macOS, Android, and iOS.

## Notes

1. The firmware must correspond strictly to the device model to avoid system malfunctions caused by installing a firmware for a different model.

2. Before updating, please confirm that the firmware version on the official website is higher than the current version.

3. Ensure that the NAS is powered on. During the upgrade process, keep the device powered and ensure a stable network connection. Do not power off or disconnect the network.

4. After the upgrade is completed, the device will automatically restart. Please wait for the system to finish loading.

5. If issues arise, please contact UGREEN customer service and provide the device serial number and log files.

## Q&A

**Q：What should I do if the firmware update fails?**

A：Check the integrity of the firmware file (re-download it), ensure the network is stable, and try manually updating.

**Q：What should I do if the app crashes after the update?**

A：Restart the NAS and try again. If the issue persists, try uninstalling and reinstalling the latest version.
