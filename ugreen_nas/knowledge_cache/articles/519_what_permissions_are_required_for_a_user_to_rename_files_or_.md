# What Permissions Are Required for a User to Rename Files or Folders?

> **Article ID**: `519`  
> **Category**: `Application Guide > Files > FAQ > What Permissions Are Required for a User to Rename Files or Folders?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/519  

---

To rename a shared folder or a subfile within a folder in Files, you must have "Read/Write" permission for the shared folder. This permission allows you to perform modification actions, including renaming.

## **Steps**

You can configure Read/Write permission for a regular user in either of the following ways to enable renaming operations:

**Method 1: Set Permissions via Files**

1. The administrator navigates to [Files] > [Shared Folder], selects the target folder, and right-clicks to choose "Properties".
2. In the Permissions tab, locate the target user's avatar and set their access permission for the shared folder to "Read/Write".
3. Click "OK" to apply the changes.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/5b4dfae4-c1de-4f00-bc8f-bbe905f8c66b.png)

4. After setting the permissions, you will be able to rename the shared folder in Files.

**Method 2: Set Permissions via Control Panel User Management**

1. The administrator goes to [Control Panel] > [User Management], finds the target user on the Users tab, clicks the "`...`" button on the right, and selects "Edit."

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/6ecb46f7-06cc-431c-86f8-3a1f619e35f1.png)

2. In the Permissions and Settings tab, locate the corresponding shared folder and set its access permission to "Read/Write."
3. Click "Save" to apply the changes.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250609/5a07dec8-b454-4145-9ccf-76edb7c923bc.png)

4. After completing the settings, you will be able to rename the shared folder in Files.

### **Please Note**

* **Administrator Permissions:** Administrator accounts have default "Read/Write" permission on all files in UGREEN NAS and do not require additional configuration. Administrators can rename files and folders directly.
* **Permission Activation:** All permission settings must be confirmed by clicking "OK" or "Save" to take effect before you can operate on the folders immediately.
