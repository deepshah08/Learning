# Does the Recycle Bin Use NAS Storage Space? How to Clear It?

## Applicability

**Applicable clients**: UGREEN NAS PC client (Windows/macOS) and UGREEN NAS mobile app (iOS/Android).

**Applicable version:** NAS firmware 1.16.0.0042 or later.

This document is for reference only. The actual interface and operation paths may vary slightly depending on system or app version updates. Please refer to the actual interface.

## Issue Description

Does the Recycle Bin use NAS storage space? How can it be cleared?

## Cause Analysis

Files in the Recycle Bin still use storage space. After files are deleted and moved to the Recycle Bin, they remain stored on the NAS drives. By default, the system does not automatically clear the Recycle Bin, so these files continue to take up available storage capacity.

## Solution

To free up storage space, clear the Recycle Bin using one of the following methods:

### PC

**Manual Cleanup**：

1. Open the "**Recycle Bin**" shortcut app, or click the trash icon at the bottom of the left sidebar in "**Files**".

![](https://file-us.ugreennas.com/admin/article/2026-06-15/d7dd81e8cbc6423d8d893dc286c087c7.webp)

2. Select the files that are no longer needed, then right-click and choose "**Delete**" to permanently delete them. To delete everything at once, click "**Empty all**" on the page.

![](https://file-us.ugreennas.com/admin/article/2026-06-15/92ab08403ae743679c12c586741af1d4.webp)

**Configure a Cleanup Plan**

Configure a cleanup plan in Recycle Bin settings to automatically clear expired files and free up storage space without manual maintenance.

![](https://file-us.ugreennas.com/admin/article/2026-06-15/5f101763913649bc9b64ad28c6281545.webp)

### Mobile

**Manual Cleanup**：

1. Open "**Files**", tap "**Settings**" at the top of the page to go to the tools and settings page, then tap "**Recycle Bin**".

2. In the Recycle Bin file list, find the file that is no longer needed, tap the **"…"** icon on the right, then select "**Delete**".

![](https://file-us.ugreennas.com/admin/article/2026-06-15/8771374c095248c7922477d9e0a00bd9.webp)

To delete everything at once, tap "**…**" at the top of the page, then select "**Empty Recycle Bin**".

![](https://file-us.ugreennas.com/admin/article/2026-06-15/aa85db4284ad4a0f85df06047bb49b51.webp)
