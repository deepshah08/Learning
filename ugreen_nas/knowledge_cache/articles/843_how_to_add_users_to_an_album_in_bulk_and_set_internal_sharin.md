# How to add users to an album in bulk and set internal sharing permissions?

> **Article ID**: `843`  
> **Category**: `Application Guide > Photos > FAQ > How to add users to an album in bulk and set internal sharing permissions?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/843  

---

**Applicable platforms**: UGREEN NAS PC client and web browser.

**Applicable versions**: UGOS Pro firmware 1.15.0.0114 and later.

Actual displays may vary depending on system or application versions. Some features may differ across versions; please refer to your actual interface for accuracy.

The "**Internal Sharing**" feature allows users to share albums with multiple registered NAS user accounts and assign different permissions to each user or grant unified permissions to multiple users in bulk.

### Add Users to an Album in Bulk and Set Permissions

1. Go to the target Album (e.g., Common album) details page, and click the "**Add User**" button (the "**+**" icon).

![](https://file-us.ugreennas.com/admin/article/2026-05-07/f30fe2be478d43519b9bef54a07799e5.webp)

2. In the pop-up "**Internal sharing**" window, click the "**+**" icon to add multiple users in bulk.

![](https://file-us.ugreennas.com/admin/article/2026-05-07/e11140f285b34f009e6ffd6c58355ba2.webp)

3. After adding users, select unified permissions in the "**Batch set permission**" section (view only, download, upload, or manage), or assign different permissions to individual users.

○ **View Only**: Can only browse Photos thumbnails.。

○ **Download**: Can view and download original photos.

○ **Upload**: Can view, download, upload photos, and invite others to upload photos.

○ **Manage**: Has full permissions, including downloading, uploading photos, editing information, and removing photos.

![](https://file-us.ugreennas.com/admin/article/2026-05-07/d483fcb430024273bfc2c7fb44228010.webp)

4. After completing the settings, simply exit the page for the changes to take effect.

**Note**: Photo sharing permissions follow the settings of the albums they belong to. If you need to set sharing permissions for a specific photo, it is recommended to add it to an album with the desired permissions already configured, or share it directly via an external link.
