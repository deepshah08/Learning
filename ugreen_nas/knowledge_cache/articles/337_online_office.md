# App Overview

Online Office is a collaborative office application developed based on the OnlyOffice open-source project, supporting real-time online editing. Unlike traditional cloud document services, Online Office stores all data on the local NAS device, ensuring data security while avoiding reliance on third-party cloud services, making the office experience more controllable and efficient.

**Key Features:**

1. **Supports real-time multi-user collaboration,** allowing simultaneous online editing of the same document with instant synchronization of changes to improve team efficiency.

2. **Supports multi-format downloading** and provides saving and downloading in mainstream office formats such as DOC, DOCX, XLS, XLSX, PPT, and PPTX.

3. **Supports encryption settings for Documents**, effectively preventing sensitive data leaks and enhancing information security.

4. **Supports sharing and exporting:** you can share documents with team members or directly export them as local files.

## Install the App

Open the "**App Center"**, find "**Online Office"** in the app list, and install it.

## Home Overview

After entering Online Office, the Home page consists of two sections: **a left-side menu bar** and **a right-side operation panel**, making document management and usage convenient.

**Left-side menu bar:**

● **Recently Opened**: shows recently accessed or newly created files for quick resumption of work.

● **Favorites**: displays files added to favorites for easy access to commonly used documents.

● **Settings**: change the default storage path for documents to suit personal storage needs.

**Right-side operation panel:**

● **New document**: create **Document**, **Sheet**, **Presentation**, or **Templates**.

● **Open**: import files from a local device or directly open existing files from NAS.

**Search function:**  
A search bar is provided at the top of the Home page, allowing users to enter keywords to quickly locate and find the required document.

## Online Office Settings

In the "**Online office"** settings, you can modify the default save path and import custom fonts.

Import Fonts:

You can batch select and import font packages in otf、otc、ttc、ttf formats, either from the NAS or from your computer.

On the Online office settings page, you can adjust the default save path or import custom fonts as needed, providing a more flexible document editing experience.

### Modify Default Save Path

You can change the default save path of documents to a specified shared folder for centralized management of document data.

**Steps:**

Open **[Online Office] > [Settings] > [Default save path]**, select the target path, and click "**OK"** to apply the changes.

### Import Fonts

The system supports importing custom fonts, making it easy to use specific styles or brand fonts in your documents.

Supported Font Formats: **OTF, OTC, TTC, TTF.**

You can either upload font files to a designated folder on the NAS in advance or batch select and import them from your computer directly into the Online Office.

**Steps:**

Open [Online Office] > [Settings] > [Import font], choose the source of the files, and import.

Imported fonts are applied globally within the app and can be used immediately without restarting the application.

## Document Management and Editing

**Document Management**  
In "**Recently Opened"** and "**Favorites"**, select the target file, click "**···"**, and perform the following actions:

● Open

● Add to favorites / Remove from favorites

● Rename

● Download (save to the designated storage path)

● Delete records (only available in "Recently Opened")

● Delete file

● Information (including file location, size, modification time, and creation time)

**Notes:**

● Multiple files can be selected for batch deletion.

● Favorited files can be accessed centrally from the "Favorites" list.

### Import Documents

1. Go to "**Recently Opened"**, click "**Open"**, and choose to import files from NAS or from local device (batch import supported).

2. After successful import, the editor opens automatically, allowing editing and collaboration on **Document**, **Sheet**, **Presentation**, or **Templates**.

3. All imported files will appear in the "Recently Opened" list.

**Supported formats for import:**  
csv, doc, docm, docx, docf, dotx, epub, pdf, pdf-a, rtf, ods, ots, odt, oform, ott, otp, potx, txt, fb2, html, xls, xml, xps, xlsx, xltx, ppsx, DjVu.

## Document Encryption

Online Office supports password protection for files to ensure document privacy and security. Once encrypted, a password must be entered when opening the file.

### Add a password

1. Open the document to encrypt and enter the editor.

2. From the top menu, select "**File > Protect > Add password"**.

![](https://file-us.ugreennas.com/admin/article/2025-10-21/86d9f165ec18404a86c97c57c3afc9b2.webp)

3. After entering a password, click "**OK"** to complete the setup.

![](https://file-us.ugreennas.com/admin/article/2025-10-21/5abc5abcdcf644839f60b0365ab51a07.webp)

### Change or delete a password

1. Open the encrypted document and click "**File > Protect"**.

2. To change: enter a new password and click "**OK"**.

3. To delete: click "**Delete password"** to disable protection.

Please keep your password safe. If lost or forgotten, the document cannot be opened.

## Supported File Formats in Online Office

The **Online Office** app integrates OnlyOffice by default, allowing you to preview and edit various document files directly in your browser. There is no need to download them locally—you can quickly view and process your files online.

Below is the list of currently supported formats for online viewing and editing, categorized by usage:

**Sheets**  
You can directly open and edit mainstream spreadsheet files.

● Formats: `.`csv, `.`fods, `.`ods, `.`ots, `.`xls, `.`xlsb, `.`xlsm, `.`xlsx, `.`xlt, `.`xltm, `.`xltx

**Documents**  
Supports multiple types of text documents, eBooks, and PDF files.

● Formats: `.doc`, `.docm`, `.docx`, `.docxf`, `.dot`, `.dotm`, `.dotx`, `.epub`, `.fb2`, `.fodt`, `.mht`, `.odt`, `.ott`, `.oxps`, `.pdf`, `.rtf`, `.xps`, `.pdf-a`, `.DjVu`

**Presentations**  
Supports online preview and editing of various presentation (PPT) files.

● Formats: **.**`fodp`, `.odp`, `.otp`, `.pot`, `.potm`, `.potx`, `.pps`, `.ppsm`, `.ppsx`, `.ppt`, `.pptm`, `.pptx`, `.odg`

**WPS Office File Formats**  
Compatible with common file types created in Kingsoft WPS Office.

● Document: `.wps`, `.wpt`

● Sheet: `.`et, `.`ett

● Presentation: `.`dps, `.`dpt

**Charts and Flowcharts**  
Supports opening chart files created with Microsoft Visio.

● Formats: `.`vsdm, `.`vsdx, `.`vssm, `.`vssx, `.`vstm, `.`vstx

**Note:** File compatibility and display results may vary depending on the complexity of the content (e.g., special fonts, macros, or complex charts).
