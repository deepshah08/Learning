# How to Delete a Shared Folder？

> **Article ID**: `893`  
> **Category**: `Application Guide > Files > FAQ > How to Delete a Shared Folder？`  
> **Client Compatibility**: `COMMON`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/893  

---

**Applicable Versions**: UGOS Pro firmware 1.17.0.0095 or later

The screenshots in this document are for reference only. The actual interface may vary slightly depending on the system or application version. Please refer to the interface displayed on your device.

In UGREEN NAS, deleting a top-level Shared Folder will permanently remove all contents within it, so please make sure to back up any important data before proceeding, as **this operation cannot be undone**.

## On a PC

1. Log in to the UGOS Pro system and open "**Files**".

2. Select "**Shared Folder**", then click the Tools icon on the right and choose "**Shared folder management**".

![](https://file-us.ugreennas.com/admin/article/2026-07-06/e4d3ff1d7596403e88043d815185add4.webp)

3. In the list, locate the target Shared Folder and hover your cursor over it.

4. Click the "**Delete**" button that appears.

![](https://file-us.ugreennas.com/admin/article/2026-07-06/68d2052756e34f7d94995663a4f701a5.webp)

5. In the confirmation dialog, verify the information and click "**Delete**" to permanently delete the Shared Folder.

## On a Mobile Device

1. Open the UGREEN NAS App and go to "**Files"**.

2. Tap the "**Settings"** icon in the upper-left corner and enter the "**Shared Folder Management**" page.

3. Tap the More button (usually the three-dot icon) next to the target folder, then select "**Delete**" from the pop-up menu.

![](https://file-us.ugreennas.com/admin/article/2026-07-06/dbadbfe437c447d694110a4394586d3a.webp)

4. Confirm the action to permanently delete the Shared Folder and its contents.

**Notes**:

● Before deleting a Shared Folder, it is recommended to back up important data to prevent data loss caused by accidental deletion.

● If you only want to delete certain files within a folder instead of the entire Shared Folder, go to "**Files**", select the files, and right-click to choose "**Delete**". If the Recycle Bin feature is enabled, the files will be moved to the Recycle Bin and can be restored from there.
