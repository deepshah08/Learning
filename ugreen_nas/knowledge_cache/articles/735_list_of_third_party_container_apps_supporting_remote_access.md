> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/735  

---

The following is a list of third-party container applications that support the remote access feature on UGREEN NAS. Users can remotely access the management interfaces of these container apps via web browsers, PC clients, or mobile devices, enabling seamless cross-device control.

## **Usage Tips**

● Please ensure that your UGOS Pro system firmware and container applications are updated to the latest versions. Older versions do not support remote access.

● Remote access is only available when logging in with a UGREENlink ID. Clicking a container app icon will automatically redirect you to the remote access interface.

● Users logging in via DDNS or other methods cannot use this feature.

● Some third-party apps may not yet support remote access on DH series devices. Please watch for future updates to experience this functionality once available.
