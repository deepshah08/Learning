**Supported Models**: iDX Series

**Supported Platforms**: UGREEN NAS PC Client, Web Browser

**Supported Versions**: UGOS Pro firmware 1.15.12.0051 and later

This feature is currently supported only on iDX series devices. Screenshots in this document are for reference only. Actual interfaces may vary slightly depending on system or application versions. Please refer to the actual interface displayed on your device.

## Feature Overview

**Intelligent Organization** is an AI-powered feature in "**Files**" app. Using intelligent recognition technology, it can automatically classify and organize files based on content, type, or file name. It supports natural language commands or preset rules to organize files with one click, batch add tags, and reuse historical organization plans—helping you eliminate manual sorting and quickly structure messy files.

## Quick Access

Open "**Files**", select one or more folders—or a combination of folders and files—then right-click and select "**Organize by**".

![](https://file-us.ugreennas.com/admin/article/2026-08-14/5a32e393fe564776a5bb52a121e8e1ba.webp)

## Smart File Organization

1. In "**Files**", select the target folder or file, then right-click and select "**Organize by**".

2. Select an organization method. For example, choose "**File type**" to organize the selected items by file type. Files can also be organized by "**File name**", "**Creation time**", "**Modification time**", or "**File size**".

![](https://file-us.ugreennas.com/admin/article/2026-08-14/7368e44d926a4ad8819a3ab69d8ba098.webp)

3. Continue to select an organization method, then choose "**Categorize files by** '**file type**'".

![](https://file-us.ugreennas.com/admin/article/2026-08-14/200cfc0bbf8740c38f06af23674b8453.webp)

4. When using this feature for the first time, follow the on-screen instructions to complete authorization.

![](https://file-us.ugreennas.com/admin/article/2026-08-14/151b457e39e44202869bb17c3480f8a3.webp)

5. AI will automatically prepare a file organization plan based on the selected organization type and method. If a large number of files is being processed, click Run in the background to allow the task to continue in the background.

![](https://file-us.ugreennas.com/admin/article/2026-08-14/892f34f4a4484e1984568f8b070f8986.webp)

6. Once preparation is complete, the results preview page displays the AI-generated organization plan. The following adjustments can be made:

![](https://file-us.ugreennas.com/admin/article/2026-08-14/d6cb113f325c46fcbd1b6e3afac65db8.webp)

● **Change the destination**: Change where the organized files will be stored.

● **Manage folders**: Add folders from the left panel. Right-click an existing folder to add a subfolder, rename it, or delete it.

● **Move or remove individual files**: In the right panel, right-click a file to remove it from the current folder. One or more files can also be dragged directly to another folder.

● **Handle duplicate file names**: Use the drop-down menu at the bottom to select "Skip", "Overwrite", or "Keep both".

7. After confirming that the proposed organization plan is correct, click "**Move**". The system will move the files according to the prepared folder structure.

8. Once the files have been moved, review the processing results, then click "**Done**" to finish the task. The organized files can be viewed in the selected destination folder.

![](https://file-us.ugreennas.com/admin/article/2026-08-14/ea0dabd5fbe249c4b516408b2c4e7de3.webp)

**Notes**: The time required to organize files depends on the number and size of the files. Up to 2,000 files can be processed at a time. Smart file organization is not available when only one file is selected.
