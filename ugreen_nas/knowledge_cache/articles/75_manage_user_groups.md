# Manage User Groups

> **Article ID**: `75`  
> **Category**: `Application Guide > Control Panel > User Management > Manage User Groups`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/75  

---

A "**User Group**" is a tool used to manage permissions for files and folders. It allows administrators to organize users with the same access permissions into groups. By creating user groups, administrators can efficiently manage permissions for multiple users, ensuring the security and consistency of files and folders. Below is a guide to managing user groups.

## Editing User Group

On the "**User Management**" page, select "**User Group**", click the **···** button next to the user group you want to edit, and choose "**Edit**". You can perform the following actions:

● **Modify user group information**: Change the user group name and description.

● **Add or remove members**: Select or deselect users in the member list.

● **Permission settings**: Configure the user group's permissions for shared folders (Access denied, Read/Write, or Read only).

### Permission Viewer

In the upper-right corner of the "**User Management**" page, administrators can use the "**Permission viewer**" to view each user's access permissions for shared folders, and filter the view by user or shared folder.

![](https://file-us.ugreennas.com/admin/article/2025-12-29/b52880f19eb54cd6a946fe256617a763.webp)

## Deleting User Group

1. On the "**User Management**" page, select "**User Group**", click the "**···**" button next to the user group you want to delete, and choose "**Delete**".

2. Confirm the deletion. The user group will be removed.

**Note:** Deleting a user group does not remove its members from the current device. Deleted user groups cannot be restored.
