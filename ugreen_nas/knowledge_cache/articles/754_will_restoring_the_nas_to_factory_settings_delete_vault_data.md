# Will restoring the NAS to factory settings delete Vault data?

> **Article ID**: `754`  
> **Category**: `Application Guide > Vault > Will restoring the NAS to factory settings delete Vault data?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/754  

---

**Q1: Will restoring the NAS to factory settings delete the data in the Vault?**

A1: No, it won’t. Vault data is stored in an independent partition. The reset process only clears system settings and does not format the hard drive, so the data remains intact.

**Q2: Can the Vault still be accessed after the reset?**

A2: Yes. After the system is restored, you can remount the Vault using the original password to access your files.

**Q3: Is it necessary to back up the Vault before performing a reset?**

A3: Although data won’t be lost, it’s still recommended to back up important files before the reset as an extra precaution.
