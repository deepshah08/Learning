# Why Is There No Change in Media Library Recognition After Configuring TMDB?

> **Article ID**: `602`  
> **Category**: `Application Guide > Theater > FAQ > Why Is There No Change in Media Library Recognition After Configuring TMDB?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/602  

---

**Please note: The primary function of the "Theater" app is to scrape and retrieve metadata for movie and TV show files stored on your UGREEN NAS. This includes automatically fetching posters, cast information, and other metadata to enhance your viewing experience.**

**The "Theater" app itself does not provide any video content. It only offers management and playback assistance. You will need to obtain video files from other sources and add them to the library on your NAS.**

After configuring TMDB, the media library will not automatically refresh. To ensure that the media library correctly uses data from TMDB, you need to adjust the video information source and rescan the media library. Follow these steps:

## **Adjust Video Information Source for Library**

**1. Set Video Information Source to TMDB**

After configuration, set the video information source to TMDB to fetch posters and other related details from TMDB.

**2. Enter Library Settings**

* Open the "Theater" app and click the settings icon in the upper right corner to enter [Library].
* In the media library list, select the media library whose data source you want to change.
* Click the [···] button on the right side of the media library and select [Edit].

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/a3abc457-3d9f-44e6-ae34-2281637249d1.png)

**3. Edit Video Information Priority**

* In the edit page, locate the [Video Information] option.
* Set TMDB as the highest priority.
* Click [Apply] to save the settings.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/6ff70be3-4bf5-4a1d-b5a9-667025745222.png)

## **Rescan Library**

**1. Return to the Library Page**

After saving the settings, go back to the library page.

**2. Start Scanning**

* Click the [···] button on the right side of the media library and select [Scan].
* In the scan options, click [Scan and Replace All]. This will rescan all files in the media library and fetch the latest metadata and poster information from TMDB.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250728/305b83de-a848-4a46-a65c-a03a25316e9b.png)

By following these steps, you can ensure the library correctly uses TMDB's data and updates the information within the library.
