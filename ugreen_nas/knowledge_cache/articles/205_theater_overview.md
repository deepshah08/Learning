The descriptions in this document are for reference only. The interface and operation paths may vary depending on system or app updates, please refer to the actual interface.

## Introduction

**Theater** is used to centrally manage and play video content stored on the NAS. After creating a media library and linking video folders, the system scans the video files in those folders and intelligently identifies movie information based on file names. Once identified, it can automatically match details such as posters, descriptions, cast, and crew.

Theater is available on UGREEN NAS desktop, mobile, and TV clients, with viewing data synced across devices.

## Homepage Overview

After opening Theater, a carousel appears at the top of the homepage and can display up to five items. Scroll down to view other sections. You can control which sections are displayed on the homepage and adjust their order under "**Settings**" > "**Homepage**".

The "**Search**" and "**Settings**" options are located at the top of the Theater page.

## Sidebar Overview

The Theater sidebar provides quick access to different content categories.

● **Recently Played**: Displays recently played videos.

● **My Favorites**: Displays videos you have added to Favorites.

● **Folder**: Displays folders linked to media libraries, allowing you to browse videos by folder.

● **Collection**: Displays series automatically grouped by the system. Movies or TV shows from the same series are grouped into a collection. You can also create collections manually.

● **Library**: Displays media libraries created by the user. Click a media library to view the videos it contains.

● **Categories**: Categorizes videos from all media libraries by type, including movies, TV shows, and others.

## Media Library Identification

After a media library is linked to a folder containing videos, the system scans the video files in that folder. Once the scan is complete, it intelligently identifies movie information based on the video file names and matches the following details:

● Movie posters

● Movie descriptions

● Cast and crew information

● Movie category information

Click a movie poster to open the movie details page.

## Cloud Drive Videos and STRM Files

If a folder linked to a media library contains `strm` files, Theater can identify the movie posters associated with the `strm` files and play the linked videos stored on cloud drives.

Theater media libraries also support folders from cloud drives mounted through "**Network folder**" in "**Files**". Once linked, Theater can identify and play video content stored in those cloud drive folders.

## Video Playback

The Theater player supports a variety of video formats. During playback, the following options are available:

● Video quality selection

● Subtitle selection

● Audio language selection

● Video display adjustments

● External subtitles & online subtitle downloads

For HDR and Dolby Vision content, the player provides optimized color reproduction.

## Settings Overview

Theater provides multiple management options in Settings.

### Navigation Menu

The navigation menu is the sidebar on the left. Here, you can choose which items are displayed in the sidebar and adjust their order.

![](https://file-us.ugreennas.com/admin/article/2026-08-17/47ab3a37414a4b7ab640b9199c5ca429.webp)

### Homepage Management

Used to manage the content displayed on the homepage. You can configure:

● Whether to display the carousel

● Carousel source

● Whether to display homepage modules

● Homepage module order

![](https://file-us.ugreennas.com/admin/article/2026-08-17/397709629c9b4ecea9c60b827eff6523.webp)

### Content Cards

Used to configure the information displayed on video cover cards. You can choose whether to show ratings and resolution on the covers.

![](https://file-us.ugreennas.com/admin/article/2026-08-17/cd1277978e434aafb7c15c1e8c62e515.webp)

### Library

Used to create and manage media libraries. Supported actions include:

● Create a media library

● Edit media library settings

● Rename a media library

● Scan a media library

● Remove a media library

![](https://file-us.ugreennas.com/admin/article/2026-08-17/7e92b0e6f5074339a8781f030d040beb.webp)

### Data Source

Used to configure services related to movie identification. You can configure:

● TMDB API

● Host settings

● Intelligent Recognition on/off toggle

![](https://file-us.ugreennas.com/admin/article/2026-08-17/7780a560bd5545d388500ffa4f20b884.webp)

### User Permission

Used to configure media library access permissions for users on the device. Administrators can control which media libraries each user can access based on their needs.

### Media Server

Used to configure third-party software access to Theater content. You can configure or view:

● Whether third-party software can access all video resources of the current account

● The dedicated account used for third-party software connections

● Server address

● Port number

![](https://file-us.ugreennas.com/admin/article/2026-08-17/1f0f518c4b2844249a4157d6d16a087c.webp)

### Cloud Drive Playback Mode

Used to configure how cloud drive resources are played. You can configure:

● Whether to prioritize direct playback for cloud drive resources
