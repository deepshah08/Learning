# Does the Notes Support Inserting Images

> **Article ID**: `896`  
> **Category**: `Application Guide > Notes > Does the Notes Support Inserting Images`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/896  

---

## Introduction

The Notes App supports inserting images into Notes, which can be used to record screenshots, reference images, process instructions, or project materials. After an image is inserted, it will be displayed as part of the Notes content.

The Notes App supports inserting images into the Notes body, which can be used to record screenshots, reference images, process instructions, or project materials.

When inserting images, you can add images from your **Local** or the **NAS file system**. The available paths may vary depending on the actual page display.

## How to Insert Images

You can insert images through the editor toolbar or the slash command menu.

### Method 1: Insert Images Using the Toolbar

1. Open the **Notes** App and open the Notes you want to edit.

2. Move the cursor to the position where you want to insert the image.

3. Click "**Insert block**" > "**Image**" on the top toolbar of the editor.

4. Select the image location, either local storage or the NAS file system, and click Next.

5. Select the image you want to insert.

6. Wait until the image insertion is complete.

### Method 2: Insert Images Using the Slash Command Menu

1. Enter`/`in the Notes editing area.

2. Select "**Image**" from the menu.

3. Select the image location, either local storage or the NAS file system, and click Next.

4. Select the image you want to insert.

5. Wait until the image insertion is complete.

## Can I Insert Images from the NAS

Yes. When inserting an image, select "**NAS file system**", then find the image you want to insert on the file selection page. After selecting the image, follow the instructions on the page to complete the insertion.

If the NAS file system entry is not displayed on the current page, refer to the actual page available in your version.

## Notes

Before inserting images, make sure the image files can be opened properly. If an image file is too large, it may affect the Notes loading speed.

If image insertion fails, check the image format, file size, and current network connection status.
