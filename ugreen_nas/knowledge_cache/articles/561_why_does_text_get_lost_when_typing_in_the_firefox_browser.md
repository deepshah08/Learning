# Why does text get lost when typing in the Firefox browser?

> **Article ID**: `561`  
> **Category**: `Application Guide > Docker > FAQ > Why does text get lost when typing in the Firefox browser?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/561  

---

## **Issue Description:**

When typing text in input fields in the Firefox browser, some characters may occasionally go missing, disrupting normal input.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250519/626a52e3-4339-4eb6-9e21-2a65153f8dae.png)

## **Cause Analysis:**

**1. Input Method Switching Issue:**  
When using Firefox to type text, switching input methods mid-typing (e.g., from Sogou Input Method to the built-in Windows input method) may cause characters to disappear. This issue occurs with a certain probability.

**2. Input Mode Switching Issue:**  
Switching modes within the same input method (e.g., from full Pinyin to double Pinyin or Wubi) increases the likelihood of text loss. This happens more frequently.

## **Solutions:**

**1. Restart Firefox:**  
If you encounter missing characters while typing, try closing and restarting the Firefox browser. This often resolves the issue.

**2. Stick to One Input Method and Mode:**  
To avoid triggering the issue, it's recommended to use a single input method and input mode (such as full Pinyin) when working in Firefox. Minimizing frequent switching of input methods or modes can significantly reduce the chance of this problem occurring.
