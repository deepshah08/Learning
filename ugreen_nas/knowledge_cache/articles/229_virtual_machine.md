## App Introduction

Virtual Machine is a virtualization solution that allows you to create and manage multiple virtual machine instances on your NAS, supporting operating systems such as Windows, Linux, iStore, OpenWRT, and iKuai. This feature enables you to easily set up and manage virtualized environments in home or office settings.

Virtual Machine supports functionalities including snapshots, shared links, and OVA file import/export. You can use snapshots to save and restore virtual machine states, share access via generated links, or export virtual machine configurations as OVA files for others to import and use quickly.

On mobile devices, the Virtual Machine app provides essential management features including power control and shared link viewing. For access to the full range of functions, it is recommended to use the computer client.

## Installation & Access

1. Open the [App Center], locate the Virtual Machine app in the application list, and click **"Install"** to launch the installation wizard.

2. Follow the wizard prompts to complete the installation.

After installation, you can access the Virtual Machine app through the following paths:

● **Mobile**: Open the UGREEN NAS App, and tap the [Virtual Machine] icon on the home screen or in the "All" section.

● **PC**: Log in to the NAS management interface, and click the [Virtual Machine] icon in the app center or on the desktop shortcut.

## Getting Started

The Overview page displays your NAS's current CPU and memory utilization, along with the number of created virtual machines and images. You can also monitor performance metrics of running virtual machines.

By selecting the **"VM"** option in the bottom navigation bar, you can view and manage all created virtual machine instances:

● **Running Virtual Machines**: View storage location, CPU and memory load, network upload/download speeds, and perform operations such as shutdown, restart, force shutdown, or access shared links.

● **Already shutdown Machines**: Initiate startup procedures or access existing shared links.

**Note:**

To view shared links on mobile devices, the links must first be created through the desktop client's virtual machine interface. Once generated, you may tap "View shared link" in the mobile application to access the addresses.
