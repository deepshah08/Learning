# [FAQ] How do I switch the NAS appearance mode to dark mode on mobile?

> **Article ID**: `670`  
> **Category**: `Application Guide > Control Panel > FAQ > [FAQ] How do I switch the NAS appearance mode to dark mode on mobile?`  
> **Client Compatibility**: `MOBILE`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/670  

---

The UGREEN NAS mobile app supports switching the interface appearance between dark mode and light mode. Users can manually select a mode or have it follow the system settings to switch automatically. Currently, this feature is only available on mobile devices (iOS/Android); the web and PC clients do not yet support appearance mode switching. Please make sure the app is updated to the latest version.

## **Steps to set (using an ios phone as an example)**

1. Open the UGREEN NAS app and tap the [User Avatar] icon in the top left corner of the home page.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250512/9cdb1216-5a89-4348-8cf0-4f563e40b04a.png)

2. Go to [General] > [General Settings] > [Appearance Display] in sequence.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250512/5b18d078-2429-402e-b459-0917bc7835c3.png)

3. You can choose from the following three modes:

* **System Settings** (default): Automatically switches based on the current system theme；
* **Light**: Always uses the light theme；
* **Dark**: Always uses the dark theme.

1. After selecting "Dark," tap Confirm to apply the setting.
2. Return to the app’s home page to preview the display in dark mode.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250512/44954807-19bb-47d6-bccd-65a8cfd1578c.png)

## **Notes**

* Dark mode is only available in the mobile app; the web and PC clients currently do not support appearance theme settings.
* If the [Appearance Display] option is not found on certain devices, it may be due to system compatibility limitations. In such cases, the app will default to light mode.
* In “System settings” mode, when the system theme on your phone changes, the UGREEN NAS app will automatically update its interface style accordingly.
