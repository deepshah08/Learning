# Introduction to the Mini Window Mode (Picture-in-Picture) of UGREEN NAS

> **Article ID**: `694`

> **Client Compatibility**: `PC`

---

The UGOS Pro system player now supports Mini Window Mode (Picture-in-Picture), enabling users to watch video content flexibly in multitasking scenarios. This mode offers convenient control options and flexible window interactions, making it an ideal solution for use cases such as multi-screen workflows and watch-while-working scenarios.

# **Mini Window Mode Features**

1. **Drag-and-Drop and Auto-Switch Support**

Users can freely drag the window and adjust its size while in Mini Window Mode. When the window is enlarged to a size close to the default aspect ratio of the main player, the system will automatically switch back to the normal window mode—no manual action required.

2. **Basic Playback Controls Supported**

* Mini Window Mode provides convenient control buttons such as [Pause/Play], [Previous Episode], and [Next Episode].

If the first episode is playing, the [Previous Episode] button will be grayed out and unavailable.

If the last episode is playing, the [Next Episode] button will be grayed out and unavailable.

* Keyboard shortcuts are also supported (e.g., spacebar for pause/play, arrow keys for fast forward/rewind).

3. **Display and Compatibility Limitations**

* External subtitles are not displayed in Mini Window Mode. It is recommended to use normal or full-screen mode when external subtitles are needed.
* The episode-switching feature is currently only supported on PC and mobile clients.

## **Instructions for Use**

1. Open the "Theater" app, select any video, and enter the playback interface.
2. In the playback control bar, click the [Mini Window/Picture-in-Picture] button. The player will automatically switch to Mini Window Mode.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250603/1f8fb985-647e-4166-a05d-101c94d81bd9.png)

3. Users can resize the mini window by dragging its edges and freely move the entire window across the screen.
4. To exit Mini Window Mode, click the [Return to Tab] button on the mini window.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250603/3cdca920-bb7b-47e7-b1ef-2bc3e34e2a1c.png)

## **Parameter Memory Mechanism Description**

* The size and position of the mini window are stored locally, meaning the current client will retain the user's settings.
* If the user changes devices, switches terminals, or uninstalls and reinstalls the client, these settings will not sync automatically and must be reconfigured manually.

# **Usage Recommendations**

* For video content that requires external subtitles, please use the normal window or full-screen mode for playback.
* If you are sensitive to window size transitions, it is recommended to avoid enlarging the mini window to a size close to the main player to prevent automatic restoration.
