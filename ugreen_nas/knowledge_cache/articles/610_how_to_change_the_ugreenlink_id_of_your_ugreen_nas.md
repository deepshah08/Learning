# How to change the UGREENlink ID of your UGREEN NAS?

> **Article ID**: `610`  
> **Category**: `Application Guide > Control Panel > FAQ > How to change the UGREENlink ID of your UGREEN NAS?`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/610  

---

UGREENlink is a remote access feature provided by the UGOS Pro system, allowing users to access their home NAS device anytime and anywhere via mobile, computer, or web browser. By entering the UGREENlink access URL (e.g., `https://ug.link/UGREENlink ID`), users can directly reach the UGOS Pro login page.

If you need to change your current UGREENlink ID, please follow the steps below:

1. Go to [Control Panel] > [Device Connection] > [Remote Access].
2. In the input box to the right of UGREENlink ID, directly enter a new ID name.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250606/7e1e12a8-c2da-4cb8-afba-92f5f0d3686d.png)

3. After confirming the risk warning, click "Change and logout" to save the changes.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250606/88dc8386-9526-4c29-9ba8-79872f1f832f.png)

4. The system will verify the new UGREENlink ID. Once successful, a new web access link and client ID will be generated. You can use the new ID to log in.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20250606/a7aafafa-d3c4-459c-855d-c133d2f06cc1.png)

**Notes:**

* If you are currently connected to the NAS device via UGREENlink, you will need to log in again after changing the ID. It is recommended to perform this operation during idle hours to avoid disrupting normal device usage.
* The UGREENlink ID must be unique. If the ID you entered is already in use, please choose a different name and try again.
