# Where Is Notes Data Stored

> **Article ID**: `895`  
> **Category**: `Application Guide > Notes > Where Is Notes Data Stored`  
> **Client Compatibility**: `COMMON`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/895  

---

## Introduction

Notes data is stored in the **Installation Location of the Notes App**. To ensure proper App operation, Notes data is hidden by default and is not directly displayed in Files.

It is not recommended to manually locate, move, or modify these hidden data files, as this may prevent Notes from opening properly or cause data issues.

## How to Check the Notes App Installation Location

You can view the Installation Location of the Notes App in App Center.

### Viewing on a Computer

1. Open App Center and find the Notes App.

2. Click to open the App details page and view the App Installation Location.

![](https://file-us.ugreennas.com/admin/article/2026-07-07/2bc6b2bb559143eb87fe73a2626192ea.webp)

### Viewing on a Mobile Device

1. Open App Center and find the Notes App.

2. Tap to open the App details page, then swipe left or right on the information section where "Developer" is displayed to view the Installation Location.

Notes data is stored in the same location as the App installation. Currently, migrating the Notes App is not supported.

![](https://file-us.ugreennas.com/ugreen-pro/admin/article/20260707/0c8128a8-7ee7-482f-8a67-95755dc1c995.png)

## Can I Manually Back Up Notes Data

Notes data is stored in a hidden data directory and cannot be manually backed up. To save Notes content, it is recommended to use the "**Export**" feature provided by the Notes App.

You can export important Notes as PDF or Markdown files, then save them to a local computer, the NAS file system, or another secure location.
