# Summary of Files Shortcuts

> **Article ID**: `646`  
> **Category**: `Application Guide > Files > FAQ > Summary of Files Shortcuts`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/646  

---

Below are the common shortcuts and their functions in the "Files" app, designed to help users efficiently perform related operations:

**Common Operation Shortcuts**

|  |  |
| --- | --- |
| **Shortcut** | **Function** |
| F2 | Rename selected item |
| Delete | Delete selected item and move to the recycle bin |
| Ctrl + A | Select all items in the current folder |
| Ctrl + X | Cut selected item |
| Ctrl + C | Copy selected item |
| Ctrl + V | Paste copied/cut item |

**New Operation Shortcuts**

|  |  |  |
| --- | --- | --- |
| **Operating System** | **Shortcut** | **Function** |
| **Windows** | Backspace | Go to the previous folder |
| Alt + Left Arrow | Go to the previous folder |
| Alt + Right Arrow | Go to the next folder |
| **macOS** | Command+【 | Go to the previous folder |
| Command+】 | Go to the next folder |
| command+Up Arrow | Go to the previous folder |
| command+Down Arrow | Select the folder, and press to enter it |
| command+Backspace | Perform the delete operation |

**Please note:** The newly added shortcuts are only effective within the "Files" app. These shortcuts will not work when the page is in a popup state or when the mouse is focused on an input field in the operation bar.
