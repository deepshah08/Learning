# Supported Audio and Lyric Formats on NAS

> **Article ID**: `433`  
> **Category**: `Application Guide > Music > Supported Audio and Lyric Formats on NAS`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/433  

---

Music supports the following audio formats, depending on the platform:

## **Supported Audio Formats**

|  |  |
| --- | --- |
| Platform | Supported Audio Formats |
| * **PC** (Windows/macOS) * **Web Browser** | `.aac`, `.mp3`, `.wav`, `.ogg`, `.flac`, `.wma`, `.dff`, `.dsf`, `.alac`, `.aiff`, `.ape`, `.m4a` |
| **Mobile** (iOS/Android) | `.aac`, `.aif`, `.aiff`, `.ape`, `.au`, `.flac`, `.mp3`, `.wav`, `.ra`, `.dts`, `.wma`, `.ac3`, `.amr`, `.m4r`, `.mka`, `.alac`, `.m4a`, `.ogg` |

## **Supported Lyric Formats**

* **.lrc** (Standard lyric file format with timestamp support)
* External lyric files must have the same name and be stored in the same directory as the audio file for the player to recognize and display the lyrics automatically.

### **Notes**

* It is recommended to use common audio formats such as `.mp3`, `.flac`, and `.m4a` to ensure cross-platform compatibility.
* For users seeking lossless audio quality, we recommend using formats like `.flac`, `.alac`, `.ape`, or `.dsf`.
* When using web-based playback, Chrome or Firefox browsers are recommended for optimal compatibility.
* Make sure the lyric file is encoded in UTF-8 to avoid character display issues.
