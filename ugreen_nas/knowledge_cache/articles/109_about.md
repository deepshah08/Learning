# About

> **Article ID**: `109`  
> **Category**: `Application Guide > Control Panel > About`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/109  

---

Go to [Control Panel] > [About] , you can view the device's basic information and hardware specifications, storage space and partitions, storage pools and hard drive details, as well as ports used by internal services and applications. Additionally, you can participate in the device analytics improvement program and enable the WebFind service.

## **General**

You can view basic device information and hardware specifications of UGREEN NAS.

**Basic information**: Device name, UGlink ID, Device owner, Model name, Warranty expiration, System version, MAC address, SN, Last start up, Power time.

**Hardware specifications**: CPU model, Memory model UPS model, CPU clock speed, CPU cores, Memory capacity, Brand name, Number of threads, Temperature, Memory frequency, Device model, Storage.

### **To change device name**

You can rename the device by clicking on the pencil icon.

Note: The first character of the device name should be a letter and is not allowed to start or end with "-".

## Device Analysis

**Help UGREEN NAS improve its products and services**

We will collect some device, hardware and system information, which does not contain any of your personal data and does not contain any data that can be used to identify you. This is to enhance our services and provide you with a better experience.

**Enable WebFind**

Once enabled, you can find this UGREEN NAS through open the website (find.ugreen.com) on the LAN. IP address and port information collected by UGREEN is only for this service.
