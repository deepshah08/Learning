# Invite Users

> **Article ID**: `70`  
> **Category**: `Video Tutorials > User Guide > How to apply for TMDB  API Key`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/70  

---

The administrator can invite users to join the device via **QR code** or **invitation link**.

To invite users:

1. Navigate to **Control Panel > User Management > Users > Add > Invite**.

2. Click "**Settings**" to enable invitation settings. Once enabled, users can be invited through QR code or invitation link.

3. Generate a **QR code invitation** and **invitation link** on the invite user page. Share these by scanning the QR code, downloading the image, or copying the text to invite users. After users apply, they will need admin approval to join.

**Note:** The above invitation features are only supported within the local area network where the UGREEN device is located. To support internet access, please enable the UGLINK external network access feature.

4.Click "**Application List**" to view pending approval applicants and approved users.

* **Pending Approval**: Displays applicants awaiting approval. During approval, set applicant roles, user groups, emails, descriptions, and enable TA's personal folders.

* **Joined**: Displays approved applicants' information.
