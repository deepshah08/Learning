## Introduction

The Theater player on UGREEN NAS supports smart parameter memory. The system automatically saves playback settings (such as video quality, audio track, and subtitles), so you do not need to reconfigure them the next time you watch.

## Local Memory Mechanism

Some playback settings (such as volume, video quality, and subtitle preferences) are stored locally. These settings are saved only on the current device. If you switch devices, change platforms, or reinstall the client, locally stored parameters will not be carried over and must be configured again in the new environment.
