# Permission Viewer

> **Article ID**: `66`  
> **Category**: `Video Tutorials > Features Overview > Vault Quick Start Guide`  
> **Client Compatibility**: `PC`  
> **Official URL**: https://support.ugnas.com/knowledgecenter/#/detail/66  

---

To view the shared folder permissions of users within the device, click the **Permission Viewer** button, select one or more users and shared folders, and you can quickly check the corresponding shared folder permissions for each user.
