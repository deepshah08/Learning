## Introduction

The UGREEN NAS Notes App allows you to create, edit, and manage Note content. It supports common Note formats, including rich text editing, to-do lists, code blocks, tables, images, and collapsible blocks.

Note content is saved automatically, making it suitable for recording work plans, study materials, project documents, and daily reminders.

## Interface Overview

The Notes App page is mainly divided into three Sections:

● **Left sidebar**: Used to view Notebook and Section.

● **Middle list**: Used to view the list of Note in the current Section.

● **Right editor**: Used to edit Note content.

Click "**Settings**"at the bottom of the page to access the App Settings page.

![](https://file-us.ugreennas.com/admin/article/2026-07-07/6b69198197a14adf9dcdefecdd80fd44.webp)

## Create a New Note

1. Open the "**Notes**" App.

2. Select the target Notebook and Section from the left sidebar.

3. Click the "**New note**" button at the top of the middle list.

4. Enter the Note title on the first line in the editor.

5. Enter Note content in the body area.

Notes are saved automatically, so you do not need to click Save manually.

## Edit Note Content

After opening a Note, you can edit the content in the right editor.

The editor supports the following features:

● **Headings/Body text**

● **List**: Ordered list, Unordered list, and Task list

● **Bold**

● **Italic**

● **Strikethrough**

● **Link**

● **Font color**

● **Insert block**: Quote block, Code block, Highlight block, Collapsible block, Table, Image, and Divider

● **Undo/Redo**

You can use the above features from the top toolbar, or type`/`, in the editor to open the slash menu.

The insert options available in the slash menu are the same as those supported by the editor. You can quickly insert Heading, List, code Block, Table, Image, and other content.

![](https://file-us.ugreennas.com/admin/article/2026-07-07/b535e0fd446b408086ca6da42557e20d.webp)

## Create a Task List

You can insert a Task list in the editor to record tasks.

Follow these steps:

1. Type `/`at the location where you want to insert the list.

2. Select "**Task list**" and enter the task items.

3. Click the checkbox to mark the task as completed.

![](https://file-us.ugreennas.com/admin/article/2026-07-07/a0ad4dde000548ea8f8b31d64c9be003.webp)

## Use Code Blocks

Notes support inserting code blocks, making it easier to record commands, scripts, or configuration content.

After inserting a code block, you can select a language from the top-left corner of the code block,such as JavaScript, Python, or YAML.

A Copy button is available in the top-right corner of the code block, allowing you to quickly copy the code content.

![](https://file-us.ugreennas.com/admin/article/2026-07-07/730e8d39e27a410d8cfa805e105e6cdc.webp)

## Use the Table of Contents for Quick Navigation

If a Note contains multiple headings, you can use the Table of contents feature in the top-right corner of the page to quickly view the structure and jump to the corresponding section.

![](https://file-us.ugreennas.com/admin/article/2026-07-07/6db5cce20d184bd0a83d6f688e46204d.webp)

## Manage Notebook and Section

The left sidebar is used to manage Notebook and Section. You can organize Notes by categorizing them into different Notebook and Section.

Examples:

● Work notes

● Study materials

● Project documents

● Daily records

Using Section effectively can reduce the time spent searching when you have a large number of Notes.

### Create a Notebook and Hide the Sidebar

There are two shortcut buttons at the top of the left sidebar, from left to right:

● **New notebook**

● **Less**

Click "**New notebook**" to create a new Notebook.   
Click "**Less**" to hide the left sidebar and expand the editing area.

### Manage Notebook

Hover over the Notebook name and click the "**···**" icon on the right to perform the following actions:

● **Rename**: Change the Notebook name.

● **New section**: Create a new section under the Notebook.

### Manage Section

Hover over the section name and click the "**···**" icon on the right to perform the following actions:

● **Rename**: Change the Section name.

● **New note**: Create a new Note under the Section.

## Manage the Notes List

The middle list displays the Notes in the current section. Two shortcut buttons are available at the top of the list, from left to right:

● **Batch select**

● **New note**

### Manage Notes in Batch

Click "**Batch select**" to select the Notes you want to manage.

After selecting Notes, an action bar will appear at the bottom of the page. The options from left to right are:

● **Delete**

● **Move to**

● **Export**

You can batch delete, move, or export Notes as needed.

**Note**: Deleted Notes cannot be recovered. Please proceed with caution.

### Manage a Single Note

You can manage a single Note using either of the following methods:

● In the middle list, hover over the Note and click the "**···**" icon on the right.

● In the right editor, click the "**···**" icon in the top toolbar.

Both methods provide the same actions, including:

● **Export as Markdown**

● **Export as PDF**

● **Move to**

● **Duplicate**

● **Delete**

### Move Note

Click "**Move to**" to move the Note to another Section.

You can move the Note to:

● Other Sections under the current Notebook

● Sections under other Notebooks

### Export Note

Note can be exported in the following formats:

● Markdown

● PDF

Exported files can be saved to a local computer or the NAS file system.

**Note**:

● If a note contains images, the images cannot be exported when exporting in Markdown format.

● To retain images in the Note, it is recommended to export the Note in PDF format.
