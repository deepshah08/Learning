# How to Quickly Organize Files with Smart Tagging？

**Supported Models**: iDX Series

**Supported Platforms**: UGREEN NAS PC Client, Web Browser

**Supported Versions**: UGOS Pro firmware 1.15.12.0051 and later

This feature is currently supported only on iDX series devices. Screenshots in this document are for reference only. Actual interfaces may vary slightly depending on system or application versions. Please refer to the actual interface displayed on your device.

## Feature Overview

Intelligent Organization is an AI-powered feature in "**Files**" app. Using intelligent recognition technology, it can automatically classify and organize files based on content, type, or file name. It supports natural language commands or preset rules to organize files with one click, batch add tags, and reuse historical organization plans—helping you eliminate manual sorting and quickly structure messy files.

## Quick Access

Open "**Files**", select one or more folders—or a combination of folders and files—then right-click and select "**Organize by**".

![](https://file-us.ugreennas.com/admin/article/2026-08-14/66ac7e4bd57a4ad7bb89ac7500b8d61e.webp)

## Smart Tagging

1. In "**Files"**, select the target folder or file, then right-click and select "**Organize by**".

2. Select an organization method. For example, choose "**File type**" to categorize the selected items by file type. Files can also be organized by "**File name**", "**Creation time**", "**Modification time**", or "**File size**".

![](https://file-us.ugreennas.com/admin/article/2026-08-14/9bf6b763cc784460afeb9ae1f9279ce9.webp)

3. Continue to select an organization method, then choose "**Add tags to files by** '**file type**'".

![](https://file-us.ugreennas.com/admin/article/2026-08-14/ce8ce576a0a84adf8c066e1ccdbf3a24.webp)

4. When using this feature for the first time, follow the on-screen instructions to complete authorization.

![](https://file-us.ugreennas.com/admin/article/2026-08-14/485db975b1fa4a078cfcd58f86a7408f.webp)

5. AI will automatically generate a preliminary tag assignment based on the selected organization method and option. If a large number of files is being processed, click Run in the background to allow the task to continue in the background.

![](https://file-us.ugreennas.com/admin/article/2026-08-14/0ea8d764791c473dad7ad22610cf1dab.webp)

6. Once preparation is complete, the results preview page displays the AI-generated tagging plan. The following adjustments can be made:

![](https://file-us.ugreennas.com/admin/article/2026-08-14/9200a99344e848e2b77de2535e1d6d3c.webp)

● **Manage the tag list**: Add new tags from the left panel. Right-click an existing tag to rename or delete it.

● **Move or remove individual files**: In the right panel, right-click a file to remove it from the current tag. One or more files can also be dragged directly to another tag.

7. After confirming that the proposed tagging plan is correct, click "**Add**". The system will add tags to the files based on the preliminary assignment.

8. Once tagging is complete, review the processing results, then click "**Done**" to finish the task.

![](https://file-us.ugreennas.com/admin/article/2026-08-14/016d813e7dff48afaacebd45ebe97570.webp)

9. Tagged files can be viewed under "**Tag**" in the left sidebar of Files.

![](https://file-us.ugreennas.com/admin/article/2026-08-14/40867cfe91b342598fc99df13cf2b025.webp)

**Notes**: The time required to organize files depends on the number and size of the files. Up to 2,000 files can be processed at a time. Smart Tagging is not available when only one file is selected.
