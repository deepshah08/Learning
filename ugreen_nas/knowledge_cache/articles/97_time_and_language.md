## Overview

On the "**Time & Language**" page in the "**Control Panel**", you can view and adjust the current system time, manually set the date and time, enable automatic synchronization with a time server, and configure the language options of your UGREEN NAS.

![](https://file-us.ugreennas.com/admin/article/2026-01-27/a3ee30d969f24c1da070214dead9009d.webp)

## Time Zone Settings

You can select your local time zone from the time zone drop-down menu.

## Time Settings

**Automatically synchronize date and time with a server**

1. Enable "**Auto sync with time server**".

2. Select a recommended server address from the drop-down list, or enter the target server address in the "**Custom**" field.

3. Click "**Save**" to confirm that the UGREEN NAS has successfully synchronized its time with the server.

4. Click "**Apply**" to complete the configuration.

**Note:** If there are no special requirements, it is recommended to keep the default server address.

**Manually set the system date and time**

Select "**Manual set**", then specify the desired date and time.

## Language Settings

UGREEN NAS provides flexible interface language options. It currently supports multiple commonly used languages, including Simplified Chinese, English, German, Japanese, and Korean. Support for additional languages will continue to expand based on the needs of users worldwide.

You can view and switch between all available interface languages in real time within the system settings.

In the "**My Language**" section, click "**Go to Set**" to navigate to the personalization page, where you can further adjust options such as desktop layout and date and time formats.
