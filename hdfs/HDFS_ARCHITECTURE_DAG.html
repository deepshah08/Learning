Router-Based Federation (RBF)

LinkedIn Scale Subsystem

The Crux (Executive Overview)
Decouples the client namespace from individual NameNodes. A layer of stateless Router proxies exposes a single global federated namespace via a State Store (ZooKeeper/Consensus), allowing LinkedIn to scale past the single-NameNode memory ceiling (>1 billion objects) without client-side config changes.
LinkedIn Production Notes
LinkedIn operates massive multi-petabyte clusters using ViewFS and RBF to federate diverse namespaces (e.g. Member data, telemetry logs, ML training sets) across distinct NameNode pairs while providing a unified HDFS URI abstraction.
